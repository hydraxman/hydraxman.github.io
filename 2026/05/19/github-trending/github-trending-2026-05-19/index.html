1. tinyhumansai/openhuman

  • 项目简介：Your Personal AI super intelligence. Private, Simple and extremely powerful.
  • 为什么火：榜首的直接原因是“个人 AI 超级智能 + 私有化 + Rust”同时踩中三个热词：本地化、隐私和 Agent 助手。一天近四千 Star，说明开发者正在寻找不完全依赖云端大模型 App 的个人 AI 入口。
  • 技术亮点：Rust 栈意味着它更强调本地性能、资源控制和跨平台可靠性；GPL-3.0 也暗示项目希望围绕开源发行建立边界。项目页给出的“Private / Simple / Powerful”定位很清楚：不是再做一个聊天 UI，而是把个人知识、工具和模型能力封装成个人智能体。
  • 适用场景：适合想尝试本地 AI 助手、个人知识工作台、隐私优先型 Agent 产品原型的团队；风险是项目仍很年轻，生态插件、模型适配和长期维护需要继续观察。
  • 关键数据：语言 Rust；Stars 16,719；Today Stars 3,945 stars today；Forks 1,454；License GPL-3.0；最近更新 2026-05-18；Topics：暂无公开 topics；Homepage：https://tinyhumans.ai/openhuman

2. Imbad0202/academic-research-skills

  • 项目简介：Academic Research Skills for Claude Code: research → write → review → revise → finalize
  • 为什么火：Claude Code 技能生态继续升温，学术研究场景又是高频刚需：从选题、文献综述到写作、审稿和修订，都非常适合被拆成可复用的 Agent Skills。
  • 技术亮点：项目不是单一 prompt，而是把 research → write → review → revise → finalize 做成流程化技能包；Python 语言和 prompt-engineering、literature-review 等 topic 说明它更像“科研工作流模板库”。
  • 适用场景：适合研究生、科研团队、技术写作者搭建半自动文献综述/论文草稿流水线；需要注意学术引用真实性、幻觉校验和机构合规。
  • 关键数据：语言 Python；Stars 11,394；Today Stars 1,302 stars today；Forks 1,173；License NOASSERTION；最近更新 2026-05-18；Topics：academic-pipeline、academic-writing、ai-research、claude、claude-code、literature-review；Homepage：https://buymeacoffee.com/crucify020v

3. HKUDS/CLI-Anything

  • 项目简介：”CLI-Anything: Making ALL Software Agent-Native” – CLI-Hub: https://clianything.cc/
  • 为什么火：“让所有软件 Agent-Native”是当前软件自动化的核心叙事：比起训练 GUI Agent，给软件补一层可被智能体稳定调用的 CLI/Hub，更像工程上可落地的路径。
  • 技术亮点：项目提供 CLI-Hub 思路，把传统软件能力包装成命令行接口，降低 Agent 调用的不确定性；Apache-2.0 许可证也利于企业试用和集成。
  • 适用场景：适合需要把内部工具、桌面软件或复杂业务系统接入 Agent 的团队；尤其适合做自动化测试、批处理、研发工具链编排。
  • 关键数据：语言 Python；Stars 36,521；Today Stars 1,047 stars today；Forks 3,542；License Apache-2.0；最近更新 2026-05-18；Topics：暂无公开 topics；Homepage：https://clianything.cc/

4. K-Dense-AI/scientific-agent-skills

  • 项目简介：A set of ready to use Agent Skills for research, science, engineering, analysis, finance and writing.
  • 为什么火：“科学研究 + Agent Skills”正在成为新一代科研自动化的入口。项目覆盖生物信息、化学信息、临床研究、金融分析等垂直领域，容易吸引跨学科开发者。
  • 技术亮点：亮点在于领域化技能集合，而不是泛泛的聊天助手。MIT 许可证、较活跃 pushed_at 和清晰 topic 表明它希望被直接拿去拼装到 Claude/Agent 工作流里。
  • 适用场景：适合科研机构、数据分析团队、金融研究和工程分析团队做领域任务模板；风险是专业结论必须引入人工复核，不能把 Skill 输出等同于科学事实。
  • 关键数据：语言 Python；Stars 24,317；Today Stars 610 stars today；Forks 2,570；License MIT；最近更新 2026-05-18；Topics：agent-skills、ai-scientist、bioinformatics、chemoinformatics、claude、claude-skills；Homepage：https://k-dense.ai

5. supertone-inc/supertonic

  • 项目简介：Lightning-Fast, On-Device, Multilingual TTS — running natively via ONNX.
  • 为什么火：端侧多语言 TTS 是 AI 应用落地的关键基础设施：成本低、延迟低、隐私好。Swift + ONNX 的组合，明显面向 iOS/桌面端原生体验。
  • 技术亮点：项目强调 Lightning-Fast、On-Device、Multilingual，并围绕 ONNX 运行时适配多平台；topic 覆盖 iOS、Flutter、Go、Java、C#，说明它不是只服务单一 Demo。
  • 适用场景：适合移动 App、离线播报、教育产品、无障碍工具和需要低延迟语音反馈的 Agent；需要评估音色授权、模型体积和不同设备性能。
  • 关键数据：语言 Swift；Stars 8,246；Today Stars 755 stars today；Forks 841；License MIT；最近更新 2026-05-18；Topics：cpp、csharp、flutter、go、ios、java；Homepage：https://huggingface.co/spaces/Supertone/supertonic-3

6. ggml-org/llama.cpp

  • 项目简介：LLM inference in C/C++
  • 为什么火：llama.cpp 已经是本地 LLM 推理事实标准之一，今天仍上榜，通常意味着社区围绕新模型、新量化格式或性能优化有持续关注。
  • 技术亮点：C/C++、ggml、MIT 许可证和庞大 Star 规模体现它的定位：用最少依赖把大模型跑到 CPU、GPU、移动端和边缘设备上。它的价值不是“又一个推理框架”，而是模型分发和本地推理生态的底座。
  • 适用场景：适合本地模型实验、边缘部署、离线 Agent、隐私场景和推理性能基准；门槛在于编译参数、硬件后端和量化格式选择。
  • 关键数据：语言 **C++**；Stars 110,941；Today Stars 283 stars today；Forks 18,362；License MIT；最近更新 2026-05-18；Topics：ggml

7. ruvnet/RuView

  • 项目简介：π RuView turns commodity WiFi signals into real-time spatial intelligence, vital sign monitoring, and presence detection — all without a single pixel of video.
  • 为什么火：用普通 WiFi 信号做空间智能、存在检测和生命体征监测，天然带有“黑科技”传播属性；不依赖摄像头也击中了隐私监控的痛点。
  • 技术亮点：Rust、ESP32、firmware、pose-estimation 等 topic 显示它跨越嵌入式、信号处理和 AI 推断。项目叙事强调 without a single pixel of video，核心亮点是用无线信号替代视觉输入。
  • 适用场景：适合智能家居、老人看护、隐私友好型安防、工业空间感知原型；风险是信号环境复杂，真实精度、误报率和硬件校准需要实测。
  • 关键数据：语言 Rust；Stars 59,791；Today Stars 704 stars today；Forks 7,803；License MIT；最近更新 2026-05-18；Topics：agentic-ai、densepose、esp32、firmware、mcu、mincut；Homepage：https://Cognitum.One/RuView

8. CloakHQ/CloakBrowser

  • 项目简介：Stealth Chromium that passes every bot detection test. Drop-in Playwright replacement with source-level fingerprint patches. 30/30 tests passed.
  • 为什么火：AI Agent 大规模使用浏览器自动化后，反机器人检测成为现实瓶颈。一个“可替换 Playwright、带指纹补丁的 Chromium”很容易引发自动化社区关注。
  • 技术亮点：项目声称 source-level fingerprint patches，并覆盖 bot-detection、cloudflare、captcha-bypass 等 topic。技术焦点不是写脚本，而是浏览器指纹、自动化痕迹和反检测兼容层。
  • 适用场景：适合合规的自动化测试、反爬防御研究、浏览器指纹实验和 Agent 浏览器环境评估；必须注意目标网站条款和法律边界。
  • 关键数据：语言 Python；Stars 15,021；Today Stars 1,391 stars today；Forks 1,176；License MIT；最近更新 2026-05-18；Topics：ai-agents、anti-detect、antidetect-browser、bot-detection、browser-automation、captcha-bypass；Homepage：https://cloakbrowser.dev/

9. tech-leads-club/agent-skills

  • 项目简介：The secure, validated skill registry for professional AI coding agents. Extend Antigravity, Claude Code, Cursor, Copilot and more with absolute confidence.
  • 为什么火：Agent Skills 正在从个人 prompt 文件演化成“可验证、可分发、可治理”的注册表。项目定位 secure validated skill registry，正好回应团队协作中的安全和质量问题。
  • 技术亮点：TypeScript 栈、面向 Antigravity/Claude Code/Cursor/Copilot 等多 IDE/Agent 生态，说明它试图成为技能分发层，而非某一个工具的插件。
  • 适用场景：适合技术团队沉淀内部开发规范、安全检查、代码审查和发布流程 Skill；关键挑战是技能签名、权限隔离和版本治理。
  • 关键数据：语言 TypeScript；Stars 3,967；Today Stars 1,244 stars today；Forks 345；License NOASSERTION；最近更新 2026-04-28；Topics：agent、ai、antigravity、claude-code、copilot、cursor；Homepage：https://agent-skills.techleads.club/

10. BigBodyCobain/Shadowbroker

  • 项目简介：Open-source intelligence for the global theater. Track everything from the corporate/private jets of the wealthy, and spy satellites, to seismic events in one unified interface. Hook an AI agent up to have it parse through data and find previously unseen correlations. The knowledge is available to all but rarely aggregated in the open, until now.
  • 为什么火：开放情报 OSINT 与 AI Agent 结合很有想象力：把飞机、卫星、地震等公开数据聚合到统一界面，再让 Agent 找相关性，这个叙事非常抓人。
  • 技术亮点：项目覆盖 asdb、cctv、earthquake-visualization、elonjet 等 topic，AGPL-3.0 也符合数据聚合平台的开源约束。技术亮点在于多源数据接入、地理可视化和面向 Agent 的分析接口。
  • 适用场景：适合 OSINT 研究、新闻调查、风险监控、地缘事件可视化和教育演示；风险是数据来源质量、隐私伦理与误关联。
  • 关键数据：语言 Python；Stars 7,647；Today Stars 768 stars today；Forks 1,184；License AGPL-3.0；最近更新 2026-05-18；Topics：air-force-one、airforce1、asdb、cctv、cctv-cameras、cctv-surveillance

今日观察

今天最值得注意的不是某一个单点项目，而是“Agent 能力产品化”的速度：技能库负责沉淀流程，CLI/浏览器/本地推理负责打通工具边界，端侧语音和个人 AI 助手负责把能力带到用户设备上。换句话说，开源社区正在把大模型从“聊天窗口”拆成一组可以被调用、验证、部署和治理的工程组件。
