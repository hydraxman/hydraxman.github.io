今天的 GitHub Trending Daily 几乎被一个关键词包圆——Skills。10 个项目里有 7 个直接服务 AI Coding Agent：Anthropic 官方插件目录、Karpathy 风格的 CLAUDE.md、.NET 官方 Skills、754 条网络安全 Skills、codegraph 代码知识图谱、Understand-Anything 知识图谱式 codebase 解读、以及 Chrome DevTools 官方 MCP。Agent 工程层的“技能/插件/上下文图”三件套正在成为 2026 年度最确定的开源主线。

剩下的 3 个项目则给了榜单一些“非 Agent”味道：Fincept Terminal 用开源方式重做 Bloomberg 终端、rohitg00 的 AI 工程从零课程被工程师集体补课、presenton 想做开源版的 Gamma/Beautiful AI 演示文档生成器。三者都说明：在 Agent 浪潮之外，金融数据基础设施、AI 工程教育和生产力工具仍然是中坚刚需。

1. Lum1104/Understand-Anything

  • 项目简介：把任意代码仓库一键转成可交互的知识图谱，允许搜索、提问、漫游节点，并已经接通 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等主流 Coding Agent。
  • 为什么火：今天 +2,331 stars 直接登顶。Coding Agent 的下一战是「上下文」，单纯 grep + 全文检索已经被 token 账单和盲读毁掉；Understand-Anything 把 codebase 转成图，节点级取上下文，这是过去半年所有 AI 编辑器都在收敛的方向。
  • 技术亮点：TypeScript + Web 端可视化的知识图谱，主打“图谱即记忆”——把 codebase 结构、关键函数、调用关系沉淀成 Karpathy-style LLM Wiki，可作为 Agent 的长期记忆 / 业务知识库。仓库 topic 显式标注 karpathy-llm-wiki、knowledge-graph、vibe-coding，思路非常清晰。
  • 适用场景：接手陌生大仓库前先建图扫一遍；给团队新人做“可点的代码地图”；用作 AI Agent 的长期上下文记忆层。
  • 关键数据：语言 TypeScript；Stars 21,043；Today Stars +2,331；Forks 1,881；License MIT；最近更新 2026-05-23；Topics：claude-code、knowledge-graph、karpathy-llm-wiki、codebase-analysis、vibe-coding；Homepage：https://understand-anything.com

2. anthropics/claude-plugins-official

  • 项目简介：Anthropic 官方维护的 Claude Code 插件目录 (Marketplace)，集中收录通过审核的 agents、skills、commands、hooks、output styles、MCP servers。
  • 为什么火：单日 +2,172 stars，连续三天稳居前二。第三方插件野蛮生长之后，Anthropic 把“可信插件目录”收归官方，相当于 Claude Code 的“App Store 心智”正式落地。
  • 技术亮点：仓库极简，靠 Python 脚本 + 标准化的 marketplace.json / plugin.json manifest 完成索引。用户一条 /plugin marketplace add anthropics/claude-plugins-official 就能挂载整个目录；价值不在代码量，在“治理 + 收录权”。
  • 适用场景：给 Claude Code 装可信插件、研究官方插件目录结构、把自家插件提交进官方收录。
  • 关键数据：语言 Python；Stars 26,281；Today Stars +2,172；Forks 2,846；License —；最近更新 2026-05-23；Topics：claude-code、mcp、skills；Homepage：https://code.claude.com/docs/en/plugins

3. colbymchenry/codegraph

  • 项目简介：面向 Claude Code、Cursor、Codex、OpenCode、Hermes Agent 的预索引代码知识图谱，主打更少 token、更少工具调用、100% 本地运行。
  • 为什么火：今天 +2,434 stars，连续两天位列榜单前三。和榜首 Understand-Anything 形成有意思的镜像：Understand-Anything 偏“面向人 / 团队的可视化解读”，codegraph 偏“面向 Agent 的可检索上下文压缩”。两个项目同时火，说明“代码即图”已成共识。
  • 技术亮点：TypeScript 实现，把符号、调用、依赖、文件关系预索引成图，Agent 不再做盲读全仓 read_file，而是按节点拉最小上下文。提供预编译二进制，无需 Node 环境直接跑，对企业落地非常友好。
  • 适用场景：中大型代码库接 AI 编辑器；想压低月度 token 成本的工程团队；本地隐私优先、不能上云的部门。
  • 关键数据：语言 TypeScript；Stars 19,093；Today Stars +2,434；Forks 1,049；License MIT；最近更新 2026-05-23；Topics：暂无；Homepage：—

4. rohitg00/ai-engineering-from-scratch

  • 项目简介：一份覆盖 Transformers、深度学习、强化学习、Agents、MCP、群体智能的 AI 工程“从零搭建”课程，配套 Python / TypeScript / Rust 多语言实现。
  • 为什么火：今天 +1,523 stars。AI 工程岗位需求继续涨，但市面教程严重碎片化——这个项目把课程 + 代码 + 项目串成一条线，等于一份 2026 年的“AI 工程师入职手册”。
  • 技术亮点：内容覆盖从 NLP / CV 基础到 LLM、Agents、MCP 全栈；不是纯笔记，每个模块附带可跑代码与 Mini 项目；多语言实现（Python 为主、TS/Rust 实战）也对应了真实 AI 工程的多技术栈现实。
  • 适用场景：想从全栈工程师转 AI 工程的人；带新人的团队 Lead；面试前想系统补漏的资深工程师。
  • 关键数据：语言 Python；Stars 13,512；Today Stars +1,523；Forks 2,532；License MIT；最近更新 2026-05-23；Topics：ai-engineering、agents、llm、mcp、from-scratch；Homepage：https://aiengineeringfromscratch.com

5. Fincept-Corporation/FinceptTerminal

  • 项目简介：开源版的 Bloomberg 终端——一个集行情、市场分析、投研、宏观数据、量化回测的桌面金融工作站。
  • 为什么火：单日 +537 stars。Bloomberg Terminal 单席年费 ~2.5 万美金长期被诟病；个人投资者、独立量化、新兴市场买方都在找替代，FinceptTerminal 几乎是目前社区最完整的开源候选。
  • 技术亮点：Python + Qt 桌面 GUI，C++ 加速核心；模块化设计可以接入券商 API、AI Agents 做投资研究、机器学习做信号挖掘；Topic 直接写明 bloomberg-terminal、ai-agents、quantitative-finance。
  • 适用场景：个人投资者要把 Bloomberg 砍掉一根成本线；独立量化研究员；金融科技初创做内部投研工具的起点项目。
  • 关键数据：语言 Python；Stars 23,057；Today Stars +537；Forks 3,181；License NOASSERTION；最近更新 2026-05-19；Topics：bloomberg-terminal、algorithmic-trading、quantitative-finance、ai-agents、investment-research；Homepage：https://fincept.in

6. multica-ai/andrej-karpathy-skills

  • 项目简介：一份 CLAUDE.md，把 Andrej Karpathy 公开发言里关于“LLM 写代码常见坑”的观察提炼成一组指令，丢进 Claude Code 项目根目录即可生效。
  • 为什么火：今天 +3,372 stars，是日榜实际增量第一。Karpathy 自带流量 × Claude Code 的 CLAUDE.md 机制刚被广泛接受 × “一个文件就能用”的极低上手门槛——三件事叠在一起爆炸。
  • 技术亮点：完全无代码，只是一份精心打磨的 Markdown 指令集，例如：拒绝糖衣式赞美、强调写小步可验证的代码、对错误根因穷追猎、避免“补丁式工程” 等。本质上是把人类资深工程师的 code review 直觉编码进 system prompt。
  • 适用场景：所有用 Claude Code 写生产代码的开发者；希望让 AI Agent 表现得更像 Karpathy 风格 mentor 的团队；想把自己的工程价值观沉淀成 Skills 文件参考此风格的人。
  • 关键数据：语言 —；Stars 149,336；Today Stars +3,372；Forks 15,311；License —；最近更新 2026-04-20；Topics：暂无；Homepage：—

7. dotnet/skills

  • 项目简介：.NET 团队官方维护的 AI Coding Agent Skills 集合，专门解决 Agent 在 .NET / C# 项目里上下文匮乏、规范不清的问题。
  • 为什么火：今天 +262 stars。继 Anthropic 之后，.NET 是第一个亲自下场写 Skills 的“顶级一方厂商”。这等于官方承认：Agent 编程时代的 SDK 文档不只是给人看的，更要给 Agent 看的。
  • 技术亮点：与 agentskills.io 标准对齐的 Skill 文件结构；按 EF Core、ASP.NET、Aspire、Blazor 等子方向组织；可被 Claude Code / Copilot / Cursor 等 Agent 直接挂载，相当于「.NET 官方文档的 Agent 化版本」。
  • 适用场景：所有用 AI 写 C# / .NET 项目的工程师；做 .NET 教学/咨询/官方培训的人；其他大型 SDK 厂商参考做 Agent-friendly 文档的范本。
  • 关键数据：语言 **C#**；Stars 2,713；Today Stars +262；Forks 207；License MIT；最近更新 2026-05-23；Topics：agent-skills；Homepage：—

8. ChromeDevTools/chrome-devtools-mcp

  • 项目简介：Chrome DevTools 官方 MCP server，让 AI Coding Agent 直接拿到浏览器调试能力——网络面板、性能分析、控制台、Source、Performance trace 全部可调。
  • 为什么火：今天 +437 stars。前端 Agent 之痛一直是“盲写盲跑”，不知道页面真实运行状态；Chrome 官方亲自做 MCP 等于把 DevTools 那一整套调试基础设施开放给 Agent。
  • 技术亮点：基于 Chrome DevTools Protocol，对外暴露成 MCP tools；Agent 可执行 evaluate、getConsoleLogs、getNetworkRequests、性能采样、断点等；底层借鉴 Puppeteer，但定位是“给 Agent 的调试器”，不是给脚本作者的自动化框架。
  • 适用场景：前端工程的 AI 调试；E2E 测试 Agent；性能/体验回归排查；构造接近真实浏览器环境的 Web Agent。
  • 关键数据：语言 TypeScript；Stars 41,286；Today Stars +437；Forks 2,623；License Apache-2.0；最近更新 2026-05-23；Topics：chrome-devtools、mcp-server、debugging、puppeteer；Homepage：https://npmjs.org/package/chrome-devtools-mcp

9. mukul975/Anthropic-Cybersecurity-Skills

  • 项目简介：754 条结构化网络安全 Skills，对齐 MITRE ATT&CK、NIST CSF 2.0、MITRE ATLAS、D3FEND、NIST AI RMF 五大框架，符合 agentskills.io 标准，跨 Claude Code / Copilot / Codex / Cursor / Gemini CLI 通用。
  • 为什么火：今天 +238 stars。安全是 AI Agent 落地的天然刚需，但合规与框架对齐一直是难点；这套 Skill 集合把“安全工程师的肌肉记忆 + 监管框架的字典”都打包成 Agent 可调用知识，相当于一个开源的 SOC 副驾驶。
  • 技术亮点：按威胁狩猎、事件响应、红队、云安全、恶意软件分析等细分领域组织；每条 Skill 内嵌对应 ATT&CK / NIST 编号，便于审计；以 agentskills.io 标准产出，跨 Agent 复用零成本。
  • 适用场景：SOC / DFIR 团队接入 AI Agent；安全咨询公司做合规自动化；学校做红蓝队培训；个人安全研究员的“随身知识库”。
  • 关键数据：语言 Python；Stars 7,247；Today Stars +238；Forks 1,000；License Apache-2.0；最近更新 2026-05-13；Topics：mitre-attack、threat-hunting、red-team、incident-response、claude-code；Homepage：https://mahipal.engineer/Anthropic-Cybersecurity-Skills/

10. presenton/presenton

  • 项目简介：开源 AI 演示文档生成器，提供 API 调用与自托管，定位对标 Gamma、Beautiful AI、Decktopus。
  • 为什么火：今天 +335 stars。AI PPT 的 SaaS 月费正在让中小团队和教育/咨询行业不舒服；presenton 以 Apache-2.0 + API 优先的形态出现，又支持本地化部署，吃下了“想用 AI 做 PPT 又不想交 SaaS 税”的中间市场。
  • 技术亮点：TypeScript 全栈，前端 + 后端 + REST API 一体；接入主流 LLM 做生成，输出可下载的 .pptx；提供 PPT 模板系统，支持团队级品牌定制；可作为 Agent 工具被 Claude / Cursor 调用，让“生成报告 PPT”成为一条 Tool Call。
  • 适用场景：把 PPT 生成嵌入到自家 SaaS；教育内容生成；咨询/投行的批量定制报告；任何需要把 LLM 输出落地成 .pptx 的工作流。
  • 关键数据：语言 TypeScript；Stars 6,269；Today Stars +335；Forks 1,110；License Apache-2.0；最近更新 2026-05-23；Topics：ai-presentation、powerpoint-generation、ai-agent、gamma；Homepage：https://presenton.ai
