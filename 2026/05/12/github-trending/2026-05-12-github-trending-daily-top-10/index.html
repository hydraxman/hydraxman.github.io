今天的 GitHub Trending daily Top 10 很有代表性：AI Agent 仍是主线，但热度不再只集中在“模型聊天”本身，而是向三个更工程化的方向扩散：让 Agent 操作桌面和浏览器、让普通人用自然语言做应用、以及把 AI 编码接入更便宜、更稳定的模型网关。与此同时，3D Gaussian Splatting、React 质量检查和大模型课程这类“确定能落地”的项目，也在榜单里保持存在感。

1. bytedance/UI-TARS-desktop

  • 项目简介：字节开源的多模态 AI Agent 桌面栈，围绕 Agent TARS 和 UI-TARS Desktop，把视觉模型、GUI 操作、浏览器任务和工具调用串到一起。MCP = Model Context Protocol，可以理解成让 Agent 连接外部工具和数据源的一套标准接口。
  • 为什么火：AI Agent 的焦点正在从“能不能回答”转向“能不能真实操作电脑”。UI-TARS-desktop 正好踩中 computer-use、GUI Agent、多模态执行这几个关键词。
  • 技术亮点：TypeScript 主体，配套 CLI、Web UI、桌面端和 MCP 工具接入；最近提交还在修安全头、CSRF、模型 provider 兼容等工程问题，说明不是只做 demo。
  • 适用场景：自动化桌面工作流、浏览器任务执行、内部工具操作、面向多模态 Agent 的产品原型。
  • 数据：32,908 Stars，今日新增 956，语言 TypeScript。

2. CloakHQ/CloakBrowser

  • 项目简介：一个主打隐身和反检测的 Chromium 分支，可作为 Playwright 的替代浏览器，用源码级 fingerprint patch 尽量通过 bot detection 测试。
  • 为什么火：浏览器自动化正被 Agent、爬虫、测试平台一起推高需求，但主流网站的反自动化检测也越来越强。它把“能打开页面”进一步推进到“像真实浏览器一样被识别”。
  • 技术亮点：围绕 fingerprint、Cloudflare、reCAPTCHA、Playwright 兼容做补丁；最近 release 还修了路径遍历和 GeoIP 超时保护，安全和稳定性都在补课。
  • 适用场景：浏览器自动化测试、数据采集、Agent 浏览器执行环境、反检测能力研究。需要注意：这类工具很容易触碰平台条款和合规边界，生产使用要谨慎。
  • 数据：5,933 Stars，今日新增 1,325，语言 Python。

3. yikart/AiToEarn

  • 项目简介：面向“一人公司”和创作者的 AI 内容营销智能体，目标是把内容生成、分发、互动和变现串成一套自动化流程。
  • 为什么火：AI 创作工具很多，但真正让创作者关心的是发布到哪里、怎么增长、如何变现。AiToEarn 直接把话题落在抖音、小红书、TikTok、YouTube、X 等渠道上，商业指向很明确。
  • 技术亮点：Electron/TypeScript 应用形态，支持多平台内容发布，README 中提到 MCP 接入和 OpenClaw 集成；相比单点生成工具，它更像“内容运营工作台”。
  • 适用场景：个人创作者矩阵运营、品牌内容分发、线下商户推广、自动化营销任务流。
  • 数据：10,620 Stars，今日新增 595，语言 TypeScript。

4. playcanvas/supersplat

  • 项目简介：PlayCanvas 推出的 3D Gaussian Splat Editor，用浏览器完成 3D Gaussian Splatting 内容的查看、编辑、优化和发布。3D Gaussian Splatting 可以理解成用大量带颜色和透明度的三维高斯点来重建真实场景。
  • 为什么火：空间内容、数字孪生和 3D 扫描的生产门槛正在下降，大家需要的不只是论文和模型，而是能直接处理素材的编辑器。
  • 技术亮点：基于 WebGL/WebGPU 和 PlayCanvas 技术栈，在线即可使用；近期提交集中在后处理亮度、splat 方向、发布版本等编辑体验细节。
  • 适用场景：3DGS 素材清理、网页 3D 展示、扫描场景发布、游戏/互动内容资产预处理。
  • 数据：7,258 Stars，今日新增 533，语言 TypeScript。

5. datawhalechina/easy-vibe

  • 项目简介：Datawhale 的 Vibe Coding 入门课程，面向初学者，用现代 AI 编码工具一步步学会做应用。
  • 为什么火：“会说话就能做应用”已经成为 2026 年编程教育的新入口。它火的原因不只是课程内容，而是抓住了普通人从 prompt 到产品原型的学习焦虑。
  • 技术亮点：JavaScript 课程站点，包含交互式教程、学习地图、AI 编码工具链和 OpenClaw 相关内容；结构上更像一本可在线迭代的教材。
  • 适用场景：AI 编程入门、非科班产品原型训练、团队内部 AI coding 培训、低代码/无代码转开发的过渡课程。
  • 数据：9,816 Stars，今日新增 808，语言 JavaScript。

6. decolua/9router

  • 项目简介：AI 编码模型网关，把 Claude Code、Codex、Cursor、Cline、Copilot、Antigravity 等客户端接到 40 多个模型 provider，并提供 fallback 和路由能力。
  • 为什么火：AI 编码的核心痛点已经从“有没有工具”变成“额度、价格、稳定性和 provider 锁定”。9router 的卖点正好击中高频用户。
  • 技术亮点：围绕 OpenAI-compatible provider、模型路由、自动 fallback、token 优化和 MITM 证书处理做工程封装；近期提交在修 provider 角色兼容、端口配置、Linux 证书注入等底层细节。
  • 适用场景：多模型 AI 编码、团队内部模型代理、成本控制、海外/国内 provider 混合路由。它不是让模型变聪明，而是让模型调用更可控。
  • 数据：8,177 Stars，今日新增 942，语言 JavaScript。

7. tinyhumansai/openhuman

  • 项目简介：Rust 写的个人 AI 助手，定位是私有、简单但能力强的个人 AI super intelligence，目前仍处于 early beta。
  • 为什么火：大家对“本地化、私有化、个人长期记忆”的 AI 助手兴趣越来越强，尤其是在云端助手同质化之后，能否掌握自己的数据成为新卖点。
  • 技术亮点：Rust 主体，提供桌面安装脚本，README 中强调 agentic assistant、隐私和个人集成；近期提交出现 tool-scoped memory、RPC API、prompt pinning 等记忆与工具相关能力。
  • 适用场景：个人知识助理、本地 AI 工作台、隐私敏感任务、长期记忆型 Agent 试验。
  • 数据：1,294 Stars，今日新增 501，语言 Rust。

8. millionco/react-doctor

  • 项目简介：面向 React 项目的健康检查工具，一条命令扫描代码库，给出 0 到 100 分的健康评分和可执行诊断。
  • 为什么火：Agent 写代码越多，React 项目里越容易堆出状态、effect、性能、架构和可访问性问题。react-doctor 的口号很直接：你的 Agent 会写坏 React，它负责抓出来。
  • 技术亮点：支持 Next.js、Vite、React Native，规则会按框架和 React 版本自动切换；还能把最佳实践安装给 Claude Code、Cursor、Codex、OpenCode 等编码 Agent。
  • 适用场景：React 项目体检、PR 质量门禁、AI 生成代码审查、前端团队规范落地。
  • 数据：7,935 Stars，今日新增 340，语言 TypeScript。

9. Lordog/dive-into-llms

  • 项目简介：《动手学大模型 Dive into LLMs》系列编程实践教程，来自高校课程讲义扩展，覆盖大模型入门、微调、部署、安全、GUI Agent 等主题。
  • 为什么火：大模型学习资料很多，但能把 PPT、实验手册、Notebook 和中文语境串起来的公益教程仍然稀缺。它适合学生和工程师补齐系统认知。
  • 技术亮点：以 Jupyter Notebook 和教学材料为主，强调实践而非只讲概念；README 显示后续增加了国产化大模型开发流程、数学推理、对齐、隐写术等内容。
  • 适用场景：高校课程、企业内训、大模型入门实践、研究生/开发者自学路线。
  • 数据：37,256 Stars，今日新增 451，语言 Jupyter Notebook。

10. AUTOMATIC1111/stable-diffusion-webui

  • 项目简介：经典 Stable Diffusion Web UI，基于 Gradio，长期以来都是开源文生图生态最重要的入口之一。
  • 为什么火：虽然它不是新项目，但生态惯性极强：插件、教程、模型、工作流和用户基础都在这里沉淀。哪怕今日新增只有 29 Stars，总量仍高达 16 万级。
  • 技术亮点：txt2img、img2img、inpainting、outpainting、upscale、prompt matrix、Textual Inversion 等功能完整，AGPL-3.0 许可；近期更新仍在修图像放大和 changelog。
  • 适用场景：本地 Stable Diffusion 体验、插件生态探索、传统 SD 工作流维护、AI 绘图教学。
  • 数据：162,876 Stars，今日新增 29，语言 Python。

今天热榜真正说明了什么

这份榜单的信号很清楚：开源 AI 的竞争正在从“模型能力”外溢到“执行环境”和“工作流控制”。UI-TARS-desktop、CloakBrowser、9router、openhuman 都不是单纯模型项目，而是在解决 Agent 真实落地时的上下文、浏览器、桌面、路由、记忆和成本问题。

另一个趋势是教育和应用层继续吃红利。easy-vibe、dive-into-llms 把复杂技术包装成学习路径，AiToEarn 则把 AI 能力直接对接内容变现。相比之下，stable-diffusion-webui 的上榜更像一个提醒：真正能活下来的开源项目，不一定每天讲新故事，但必须沉淀生态和用户习惯。

本期如果只看一个方向，我会看 AI Agent 基础设施；如果只挑一个最适合普通开发者立刻试的项目，react-doctor 和 easy-vibe 的上手成本最低。
