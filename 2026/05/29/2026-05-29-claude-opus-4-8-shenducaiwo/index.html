9650 亿估值之外，Claude Opus 4.8 真正值得看的两件事

5 月 28 日深夜，Anthropic 同一晚干了两件事。

一件大家都在转：完成 650 亿美元 H 轮融资，估值 9650 亿美元，第一次压过 OpenAI（8520 亿）。

另一件被融资新闻盖住了：发布 Claude Opus 4.8，距上一代 Opus 4.7 只隔了 43 天。

绝大多数中文公众号写的都是第一件事。但说实话，估值跟模型好不好用，是两件没什么关系的事。

这篇只聊第二件——把”夺回王座””断层第一”这些情绪词剥掉之后，Opus 4.8 真正值得开发者关注的，其实只有两点。

一、第一次有模型在”不撒谎”这件事上拿了满分

跑分这种东西，每代都在涨，看多了麻木。

但 Anthropic 这次官博反复强调的，不是跑分，是俩字——诚实。

具体到数字：

  • 谎报率（代码有缺陷却装没事）：Opus 4.5 是 0.40，Opus 4.7 是 0.25，Opus 4.8 是 0.00
  • 偷懒调查率（遇到要追查的问题敷衍了事）：Opus 4.7 是 25%，Opus 4.8 是 0%

这张是 Anthropic 官方放出来的 Remote Control 真实截图：用户图省事说 “Just force it”，Claude 顶回去说”不强推，会丢掉同事 11:42 的 hotfix，我帮你 rebase 了”。

两个 0%。Anthropic 说这是第一个在这项评估里拿满分的模型。

为什么这事比 SWE-Bench 多涨几个点更重要？

用过 Claude Code、Cursor、Devin 的人都被坑过：让 AI 改一段代码，它跑完拍胸脯说”搞定了”，结果跑测试一片红。这不是能力问题，是模型被训练成讨好用户——说”我做完了”比说”我没搞定这一段”得到的奖励更高，于是它就学会了报喜不报忧。

Opus 4.7 还有 25% 概率敷衍，Opus 4.8 直接归零。这是把奖励模型反向修过的结果，不是 prompt 工程能补的。

Anthropic 放了一段视频佐证。开发者在外面放风筝，让 Claude Code 后台跑代码迁移。提交被服务器拒了——同事刚 push 了个紧急修复。开发者图省事，回了句”直接强制覆盖”。

Claude 拒绝了：

不强制覆盖。那样会丢掉同事 11:42 提交的紧急修复。我已经把两边的改动合并好了，代码完全一致，提交历史也干净。已推送。

这场景的关键不是”AI 多聪明”，而是它敢顶嘴。一个能在用户图省事时说”不”的模型，才能真正放手让它跑 agent 任务。

当然，”0% 谎报率”是 Anthropic 自家的评估方式，跑别人的 benchmark 不一定还是 0。但趋势是明确的——从 0.40 到 0.25 再到 0.00，三代连续在压。

二、Dynamic Workflows：把 AI 编程从”一个人答题”改成”开工厂”

第二件事，藏在 Claude Code 的更新里，没几篇中文文章写明白。

它叫 Dynamic Workflows，目前只在 Enterprise / Team / Max 套餐的研究预览里。

简单一句话讲清楚它是什么：

以前——你让 Claude 改一个大项目，它一个人吭哧吭哧从头改到尾，token 烧光、断了从头再来。

现在——Claude 接到任务，先写一段调度脚本，把活儿拆成几十上百个子任务，撒给一群 subagent 并行干。再起另一批 agent 做审查、互相挑刺，吵到答案收敛，最后汇总给你。

调度发生在主对话之外，断了能续上。

一句话画清楚 Dynamic Workflows 是啥：中间那个戴光环的主 Claude 在指挥，外圈一群 subagent 并行干活，右下角还有专门负责挑刺审查的——以前一个人答题，现在是开工厂。

最出圈的实战，是 Bun 作者 Jarred Sumner 干的。

Bun 是个 JavaScript 运行时（Claude Code 自己就是用 Bun 打包发到几百万用户手里的），最早用 Zig 写。Sumner 一直想换 Rust，因为 Zig 内存安全太弱，调试内存泄漏调到吐。

放在过去，这是一支团队按季度算的工程。

Sumner 用 Dynamic Workflows 干了多久？

  • 约 100 万行 Rust 代码（Sumner 自己说 a million lines，原文公众号写的 75 万是另一处口径）
  • 99.8% 原有测试通过（Linux x64 glibc）
  • 从第一次提交到合并，11 天
  • 产生 6000+ 次提交，几乎没有人类逐行审查

这事社区炸锅是有道理的。

但有一句边界必须提醒：

  1. Bun 是有完备测试套件的项目。Dynamic Workflows 能跑通，是因为 99.8% 那个数字有人写好的测试在兜底——错了它能立刻知道。你自己的烂屎山项目可能连一行测试都没有，这套打法直接用上去就是灾难。

  2. token 消耗远高于普通 session。Anthropic 官博自己写的：建议从小任务试起。一次大迁移烧的钱够你自己改一个月。

  3. 这是 Enterprise/Team/Max 套餐限定。Pro 用户还摸不到。

所以这件事的真正含义不是”以后人类不用写代码了”，而是：**对已有完备测试和明确目标的迁移/重构类项目，AI 一夜之间从”辅助”变成了”主力”**。要满足这两个前提，普通业务代码还差得远。

顺手提一下的几件小事

剩下的几个升级，价值不如上面两件，但对日常使用还是有感：

  • Effort Control 五档（Low → Max）：以前你只能选模型，现在能给同一个模型选”思考力度”。简单问题挂 Low 省额度，硬骨头拉 Max。Claude Code 里还多了个 xhigh，顶到 xhigh 会自动判断是否调 Dynamic Workflows。
  • Fast Mode 降价 1/3，速度 2.5×。这是真的便宜了。
  • 价格不变：$5/M input、$25/M output，跟 4.7 一模一样。
  • Tool calling 更省：Cursor CEO Michael Truell 原话：”same intelligence with fewer steps”。同任务比 4.7 少 15% 步骤、少 35% token。

这是 Anthropic 官方原图，去掉了别家公众号的水印。注意 Terminal-Bench 2.1 那一栏 GPT-5.5 还是赢 3.6 分——这就是为什么”全面碾压”是公众号语言，不是事实。

跑分方面，SWE-Bench Pro 69.2%（比 GPT-5.5 高 10 分）、GDPval-AA 1890 Elo 断层第一、OSWorld 83.4% 第一。这些都是 Anthropic 自己挑出来的好看的项，Terminal-Bench 2.1 上 GPT-5.5 还是赢它 3.6 分——所以”全面碾压”是公众号语言，不是事实。

关于 Mythos 的那个传言

公众号最后都把”Opus 4.8 可能就是蒸馏版 Claude Mythos”当结论写，这其实是博主 Mark Kretschmann 的个人推测，Anthropic 官方没确认过。

能确认的是：

  • Claude Mythos Preview 真的存在，已经在 AWS Bedrock 和 Google Vertex AI 上以”私有预览”形式给到部分客户
  • 官方定位是新一类智能，主打长时段自治 agent 和网络安全
  • AWS 文档里它的 endpoint 名字叫 bedrock-mantle，跟普通 Claude 不是一个东西
  • 官方说”未来几周”广泛推出，前提是网络安全护栏准备好

至于 Opus 4.8 是不是它的蒸馏版——不知道，别瞎传。

给独立开发者的结论

如果你是独立开发者或者小团队 tech lead，这次发布对你只有三件 actionable 的事：

  1. Claude Code 默认换 4.8。同价格、更省 token、更不撒谎，没理由继续用 4.7。
  2. 如果你有一个有完备测试套件的迁移/重构项目，去申请 Max 套餐试一下 Dynamic Workflows。这是这次发布里唯一可能真正改变你工作方式的东西。其他都是边际改进。
  3. 9650 亿估值这件事，跟你写代码没关系。融资新闻看一眼就行，别当成”Claude 又赢了所以我要换回 Claude”的理由。

至于”AI 王座””ASI 巅峰对决”——这种话留给公众号写就好。
