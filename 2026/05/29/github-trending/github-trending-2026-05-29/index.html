今天的 Trending 是一份「AI 生产力 × 反 AI 味」的奇怪组合。

榜首的 MoneyPrinterTurbo 一天 +4,685，是「一键 AI 生成短视频」这条赛道又一次出圈；与此同时，stop-slop、taste-skill 两个「让 AI 写得别那么像 AI」的 Skill 仍然挂在前 5——一边在用 AI 大批量生产内容，一边在拼命把内容里的 AI 味洗掉，整个生态的张力肉眼可见。再叠加 obra/superpowers、affaan-m/ECC、revfactory/harness 三套 Coding Agent harness，今天的关键词就是：用 AI 干活，同时用 Skill 校准 AI。

逆势的两个项目同样耐读：FreeDomain 提供免费域名继续吃自托管/独立站红利；byoungd/English-level-up-tips 这本「老牌中文学英语指南」一夜 +2,015，说明在 AI 翻译横行的 2026 年，认真学一门语言依然有一大批人愿意点赞收藏。

1. harry0703/MoneyPrinterTurbo

  • 项目简介：输入一句话主题，AI 自动写脚本、查素材、配音、合成字幕，一键产出适合 TikTok / 抖音 / YouTube Shorts 的高清竖屏短视频。
  • 为什么火：一天 +4,685，是个人创作者和 MCN 都关心的「内容工厂」入口；模型成本降到 2026 年后，「批量生成短视频」从噱头变成了真的可日产几十条。
  • 技术亮点：Python 全栈，MoviePy 处理剪辑，接 OpenAI / Claude / 国产大模型做脚本和 TTS；模块化 pipeline，方便替换素材源和声音。
  • 适用场景：自媒体批量更新、电商带货短视频、英语听力 / 二语内容产线、AI 数字人脚本生产。

2. affaan-m/ECC

  • 项目简介：面向 Coding Agent 的 harness 框架：把 Skills、记忆、直觉、安全约束和「研究优先」开发流封装成一层可挂载的标准接口。
  • 为什么火：连续多天霸榜，说明社区把「裸 Claude/Codex 不够用，得加一层 harness」的共识具体落到了这一套实现；ecc.tools 站点也持续吸量。
  • 技术亮点：JavaScript 代理增强层，统一的 MCP/Skill 标准；可挂到 Claude Code、Codex、OpenCode、Cursor 等主流编码 Agent。
  • 适用场景：团队级 AI 编码工作流、Agent 行为约束、跨工具一致体验、企业内部最佳实践沉淀。
  • 关键数据：语言 JavaScript · Stars 197082 · Today 1,388 · Forks 29946 · License MIT · 最近更新 2026-05-28 · Topics ai-agents, anthropic, claude, claude-code, developer-tools, llm, mcp, productivity · Homepage https://ecc.tools

3. Leonxlnx/taste-skill

  • 项目简介：一个 Skill 文件，专门给 AI 灌「审美」，防止它写出千篇一律的 Bootstrap 模板风前端和满屏 emoji 的 README。
  • 为什么火：搭配 stop-slop 一起被讨论，是「AI 内容反 AI 化」浪潮的代表；单文件即用，对设计师 / 产品 / 独立开发者特别友好。
  • 技术亮点：Shell + Markdown 结构化 Skill，遵循 Claude Code / Codex / Cursor 通用 Skill 规范；侧重前端排版、字体、留白、配色指导。
  • 适用场景：让 Coding Agent 输出有质感的 Landing Page / 文档 / Slide；做品牌一致性约束；个人项目去 AI 味。

4. hardikpandya/stop-slop

  • 项目简介：单文件 Skill，专治 AI 写作里的「slop」——也就是套话、罗列、emoji 砸场、过度礼貌等 AI 特征。
  • 为什么火：模型越大，写出的文字越「干净也越雷同」，这种「反 AI 味」工具正中创作者的痛点；连续多日上 Trending。
  • 技术亮点：纯 Markdown / 提示词工程，无依赖；可作为系统提示加载到任何模型，也可拆成模块化 Skill 在 Coding Agent 内复用。
  • 适用场景：博客 / 公众号写作、PR 文案、产品文档、邮件 / 演讲稿润色，需要「读着像人」的所有场景。

5. twentyhq/twenty

  • 项目简介：开源、现代、可自托管的 CRM，定位是 Salesforce / HubSpot 的开源替代。
  • 为什么火：SaaS 涨价潮持续，团队开始重新评估自托管 CRM；good-first-issue 标签丰富，社区活跃度极高。
  • 技术亮点：TypeScript + GraphQL，模块化 schema，原生支持自定义对象、视图、自动化；UI 走 Notion 风格的轻量数据库感。
  • 适用场景：中小团队替换 SaaS CRM、独立开发者管理客户与销售管道、研发团队做内部线索 / OKR 跟踪。

6. DigitalPlatDev/FreeDomain

  • 项目简介：DigitalPlat 出品的免费域名平台，长期挂榜的「免费基础设施」系列。
  • 为什么火：独立站、个人博客、小工具 SaaS 在 AI 时代继续扩张，免费域名是低门槛入场券；多语言文档 + 极低准入门槛带来稳定的日 Star 增长。
  • 技术亮点：HTML 静态站点 + 简单的申请流程，配合 DNS 服务给出免费二级域名；申请规则透明，运营成本低。

7. byoungd/English-level-up-tips

  • 项目简介：一份中文写的「英语进阶高级指南」，从词汇、听力到原版书与发音，给中文程序员的英语学习路线。
  • 为什么火：在 AI 翻译几乎免费的时代，仍有大量人「想真正掌握英语」；老牌项目一夜 +2,015，说明这种「逆 AI」需求是真实存在的。
  • 技术亮点：纯 Markdown 文档，结构清晰，可读性高；社区维护多年，链接和书单持续更新。
  • 适用场景：技术人系统学英语、刷阅读 / 听力、面试 / 留学 / 远程工作沟通准备、为家人和朋友推荐学习路线。

8. microsoft/markitdown

  • 项目简介：微软出品的「万物转 Markdown」工具：把 Word、Excel、PPT、PDF、图片、HTML、音频等统一转成 LLM 友好的 Markdown。
  • 为什么火：RAG 与 Agent 应用第一步就是「文档归一化」，markitdown 几乎是这一步的事实标准；近期发布支持 AutoGen extension，又被 Agent 圈拉了一波。
  • 技术亮点：Python，模块化转换器架构，可挂 OpenAI Vision 处理图片；可作为 AutoGen / LangChain 工具调用，也能命令行批量处理。
  • 适用场景：知识库预处理、企业文档 RAG、Agent 文件读取、做 dataset 时统一原始资料格式。

9. obra/superpowers

  • 项目简介：obra 维护的 Claude Code「超能力」Skill 包，把若干高质量 prompt / 工作流封装成可直接挂载的 skill 集合。
  • 为什么火：Claude Code skill 生态已成事实标准，superpowers 是这套生态里少数「上手即用」的高质量参考实现；多日榜上有名。
  • 技术亮点：Shell + Markdown 组成的 skill 包，结构清晰，附 README 和测试用例，可被 Hermes Agent 等多种客户端复用。
  • 适用场景：搭建自己的 Claude Code 工作流、做团队 skill 模板、研究 skill 命名 / triggering 规范。
