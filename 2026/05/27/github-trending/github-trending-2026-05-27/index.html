今天的 GitHub Trending 几乎被一个词承包了——Skill。

从 Anthropic 官方的 knowledge-work-plugins，到 ECC 这种「Agent 调教框架」，再到 stop-slop、taste-skill 这类一文件即用的「去 AI 味」Skill，前 10 里有 8 个是围绕 Coding Agent / Skill 生态在打。Claude Code、Codex、OpenCode、Cursor 这些工具的差距正在被一层层 Skill 抹平，社区把价值从「模型本身」迁移到了「围绕模型的工艺」上。

逆势的两个项目同样值得看：Jellyfin 和 awesome-free-apps 一起说明，「逃离订阅、自托管、找免费替代」 仍是开发者圈一股稳定的暗流。AI 在卷 Skill 的同时，普通用户在悄悄重新审视自己每月的账单。

1. Lum1104/Understand-Anything

  • 项目简介：把任意代码库一键变成可探索的「知识图谱」，让 AI 在结构上理解代码而不是死记字符串。
  • 为什么火：Karpathy 风格的 LLM Wiki 思路落地为通用工具，并且兼容 Claude Code / Codex / Cursor / Copilot / Gemini CLI 等所有主流 Agent，正好踩在「Skill / Codebase Memory」这波风口上。
  • 技术亮点：TypeScript 全栈 + 交互式图谱前端；把代码切成可索引节点，叠加问答与搜索；可作为 MCP/Skill 形态嵌入各家 Coding Agent。
  • 适用场景：上手陌生大型仓库、新成员入职导览、Agent 长上下文记忆、代码审查的依赖透视。
  • 关键数据：语言 TypeScript · Stars 35296 · Today 4,721 · Forks 2848 · License MIT · 最近更新 2026-05-26 · Topics antigravity-skills, business-knowledge, claude-code, claude-skills, codebase-analysis, codex, codex-skills, developer-tools-ai-agent · Homepage https://understand-anything.com

2. affaan-m/ECC

  • 项目简介：面向 Coding Agent 的「调教框架」：把技能、直觉、记忆、安全和「研究优先」开发流封装成 harness。
  • 为什么火：一天 +1,912，背后是社区对「裸 Claude/Codex 不够用，得加一层 harness」的共识；ECC 把这一层做成开箱即用，还配了 ecc.tools 站点。
  • 技术亮点：JavaScript 实现的代理增强层，覆盖 skills、memory、安全与研究流程；标准 MCP/Skill 接口，可挂载到 Claude Code、Codex、OpenCode、Cursor 等。
  • 适用场景：团队级 AI 编码工作流、Agent 行为约束、跨工具一致体验、企业内部最佳实践沉淀。
  • 关键数据：语言 JavaScript · Stars 194106 · Today 1,912 · Forks 29946 · License MIT · 最近更新 2026-05-25 · Topics ai-agents, anthropic, claude, claude-code, developer-tools, llm, mcp, productivity · Homepage https://ecc.tools

3. rohitg00/ai-engineering-from-scratch

  • 项目简介：「从零做 AI 工程」系列课程：从深度学习到 Transformer、Agent、MCP、强化学习全链路，跟着代码写一遍。
  • 为什么火：口号「Learn it. Build it. Ship it for others.」精准切中转岗 AI 工程的开发者，主题覆盖 LLM / MCP / Swarm / RL / Computer Vision，标签丰富。
  • 技术亮点：Python 为主，配合 Rust/TypeScript 示例；按模块拆分的渐进式 repo，搭配独立站点 aiengineeringfromscratch.com。
  • 适用场景：系统学 AI 工程、做内训教材、个人作品集、面试准备的实战素材。
  • 关键数据：语言 Python · Stars 20509 · Today 2,169 · Forks 3426 · License MIT · 最近更新 2026-05-26 · Topics agents, ai, ai-agents, ai-engineering, computer-vision, course, deep-learning, from-scratch · Homepage https://aiengineeringfromscratch.com

4. anthropics/knowledge-work-plugins

  • 项目简介：Anthropic 官方开源的「知识工作者插件库」，主要供 Claude Cowork 使用。
  • 为什么火：官方亲自下场做 Skill / Plugin 生态，相当于给 Claude Cowork 立了一个开放标准，社区跟进意愿极强，一天 +1,698 stars。
  • 技术亮点：Python 插件集合，遵循统一 manifest；可被 Claude Cowork 直接加载，也可作为其它 Agent 的 Skill 参考实现。
  • 适用场景：为公司 Claude Cowork 自建插件、研究官方 Skill 规范、为内部知识库做 AI 入口。
  • 关键数据：语言 Python · Stars 16558 · Today 1,698 · Forks 1945 · License Apache-2.0 · 最近更新 2026-05-26 · Topics — · Homepage —

5. mukul975/Anthropic-Cybersecurity-Skills

  • 项目简介：754 个结构化的网络安全 Skill，映射到 MITRE ATT&CK、NIST CSF 2.0、ATLAS、D3FEND 与 NIST AI RMF 五大框架。
  • 为什么火：把「合规框架 + Agent Skill」缝在一起，安全团队拿来就能跑；遵循 agentskills.io 标准，兼容 Claude Code、GitHub Copilot 等。
  • 技术亮点：Python + 结构化 YAML/Markdown Skill，覆盖红队、蓝队、威胁情报、事件响应、云安全、恶意代码分析等子域。
  • 适用场景：SOC 自动化、红蓝对抗演练、安全合规检查、CISO 用 AI Agent 巡检企业资产。

6. hardikpandya/stop-slop

  • 项目简介：一个专门用来「去 AI 味」的 Skill 文件——让 LLM 输出读起来不像 AI。
  • 为什么火：在「AI 味泛滥」的当下，单文件 Skill 直接命中所有内容创作者的痛点；MIT 协议、复制即用，传播速度极快。
  • 技术亮点：纯 prompt/skill 文件，没有依赖；定义了一组「禁词、禁句式、禁套路」的修订规则，可挂到任何支持 Skill 的 Agent。
  • 适用场景：写公众号、写邮件、写营销文案、做内容审核之前做一次「去 slop」。
  • 关键数据：语言 — · Stars 4914 · Today 547 · Forks 401 · License MIT · 最近更新 2026-03-17 · Topics — · Homepage —

7. Leonxlnx/taste-skill

  • 项目简介：Taste-Skill：给 AI 加上「品味」，专治生成结果千篇一律、设计感为零。
  • 为什么火：和 stop-slop 同一波情绪，但定位更宽——不仅是文本，还覆盖前端 / 设计 / vibecoding；附带 tasteskill.dev 官网，传播形态完整。
  • 技术亮点：Shell 脚本 + Skill 配置，可接入 Claude Code、Codex 等；强调对生成内容的「设计品味」约束。
  • 适用场景：前端代码与 UI 生成、Landing Page、设计稿到代码的 vibecoding、低代码/无代码生成质量提升。
  • 关键数据：语言 Shell · Stars 21241 · Today 1,440 · Forks 1719 · License MIT · 最近更新 2026-05-26 · Topics agent, ai, claude, claude-code, codex, coding, design, frontend · Homepage https://tasteskill.dev

8. DigitalPlatDev/FreeDomain

  • 项目简介：DigitalPlat 免费域名平台：人人都能注册自己的免费域名。
  • 为什么火：16.7w stars 老牌项目仍在 trending，说明持续有新用户涌入；「免费域名」对独立开发者、学生、AI 应用 demo 都是刚需。
  • 技术亮点：HTML/前端 + 后端服务，AGPL-3.0；提供子域和完整域名注册流程，配套 domain.digitalplat.org 在线申请。
  • 适用场景：个人博客、独立项目、AI 产品 MVP、临时演示站点。

9. jellyfin/jellyfin

  • 项目简介：Jellyfin：免费开源的家庭媒体服务器，对标 Plex、Emby，无任何付费墙。
  • 为什么火：今天唯一的「非 AI」项目，逆势上榜，说明自托管和「逃离订阅」的需求依旧旺盛；GPL-2.0 让它在 NAS 圈一直是默认选择。
  • 技术亮点：C# / .NET 实现的媒体服务后端 + API，跨平台部署，前端有多个独立客户端。
  • 适用场景：家庭影音库、NAS 自托管、替代 Plex Pass、配合硬解显卡做远程影院。
  • 关键数据：语言 C# · Stars 52334 · Today 91 · Forks 4869 · License GPL-2.0 · 最近更新 2026-05-26 · Topics csharp, dotnet, hacktoberfest, jellyfin · Homepage https://jellyfin.org

10. Axorax/awesome-free-apps

  • 项目简介：一份精挑细选的「全平台免费应用」清单：PC、Mac、Linux、iOS、Android 全覆盖。
  • 为什么火：Awesome List 老套路，但选品狠、分类清晰，正好接住「停止订阅 / 寻找免费替代」的情绪；JS 驱动的可浏览展示让传播更轻松。
  • 技术亮点：JavaScript + 数据驱动列表，主仓库即可作为可读站点；CC/NOASSERTION 许可，社区贡献门槛低。
