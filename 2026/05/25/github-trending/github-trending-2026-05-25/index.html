今天的 GitHub Trending Daily 出现两条清晰主线。第一条仍然是 Claude Code 生态——榜单 10 个项目里有 6 个直接服务于它：Anthropic 官方的开发者插件目录 (claude-plugins-official) 和知识工作插件目录 (knowledge-work-plugins) 双双在榜，Karpathy CLAUDE.md (multica-ai/andrej-karpathy-skills) 持续吸量，free-claude-code 蹭住订阅焦虑，多 Agent 管理平台 multica 把 Agent 当队友管理，另一边的 codegraph 则给 Agent 做预索引上下文。Anthropic 同一天两份官方插件仓库登榜，是 Claude 平台正式从 Coding Agent 向 Office/Knowledge Worker 扩张的明确信号。

第二条主线是 「代码即知识图谱」：榜首 Understand-Anything (+3,987) 和第 8 名 codegraph (+2,993) 互为镜像，一个面向人和团队的可视化解读，一个面向 Agent 的可检索上下文压缩。两个完全独立的项目同时在 Top 10 高位，说明「图谱即代码记忆」已经从 PoC 走向被工程化采购。剩下的 ai-engineering-from-scratch 与 earendil-works/pi 给了榜单一些「非 Anthropic」的味道——AI 工程教育和开源 Agent toolkit 全家桶仍是中坚刚需；唯一一个非 Agent 项目 Kronos 则代表了垂直领域 (金融) foundation model 路线的回归。

1. Lum1104/Understand-Anything

  • 项目简介：Graphs that teach > graphs that impress. Turn any code into an interactive knowledge graph you can explore, search, and ask questions about. Works with Claude Code, Codex, Cursor, Copilot, Gemini CLI, and more.
  • 为什么火：今天 +3,987 stars 蝉联榜首，连续两天霸榜。Coding Agent 的下半场是「上下文工程」，把 codebase 转成可遍历、可问答的知识图谱，比单纯 grep + 全文 embedding 更能压低 token 又能保留语义，是各家 AI 编辑器都在抢的方向。
  • 技术亮点：TypeScript + Web 前端做图谱可视化，把仓库结构、关键函数、调用关系沉淀成 Karpathy-style LLM Wiki。可作为 Claude Code / Codex / Cursor / Copilot / Gemini CLI 等 Agent 的长期记忆层。Topic 显式标注 karpathy-llm-wiki、knowledge-graph、vibe-coding，定位清晰。
  • 适用场景：接手陌生大仓库前先建图扫一遍；给团队新人做「可点的代码地图」；作为 AI Agent 的长期上下文记忆与业务知识库。
  • 关键数据：语言 TypeScript；Stars 25,209；Today Stars +3,987；Forks 2,183；License MIT；最近更新 2026-05-24；Topics：antigravity-skills、business-knowledge、claude-code、claude-skills、codebase-analysis、codex；Homepage：https://understand-anything.com

2. rohitg00/ai-engineering-from-scratch

  • 项目简介：Learn it. Build it. Ship it for others.
  • 为什么火：单日 +1,836 stars 冲到次席。AI 工程教育依然是 2026 年最大的「补课刚需」——从 Transformer 原理到 Agents/MCP/Swarm 全栈，一份开源课程把零散的知识图谱串起来，工程师社区集体收藏。
  • 技术亮点：Python 为主，覆盖 Deep Learning / NLP / CV / RL / Generative AI / Agents / MCP / Swarm Intelligence 等十余个 topic，跨 Python/Rust/TypeScript 多语言示例，配套官网 aiengineeringfromscratch.com，定位是「学完能 ship」的端到端 AI 工程路径。
  • 适用场景：想系统补齐 AI 工程的开发者；带新人入门的团队；准备面试和转岗 AI Infra 的工程师。
  • 关键数据：语言 Python；Stars 15,559；Today Stars +1,836；Forks 2,795；License MIT；最近更新 2026-05-23；Topics：agents、ai、ai-agents、ai-engineering、computer-vision、course；Homepage：https://aiengineeringfromscratch.com

3. anthropics/claude-plugins-official

  • 项目简介：Official, Anthropic-managed directory of high quality Claude Code Plugins.
  • 为什么火：今日 +1,179 stars，连续多日稳居前三。Anthropic 把「可信插件目录」收归官方，相当于 Claude Code 的 App Store 心智正式落地，第三方插件野蛮生长之后的治理拐点。
  • 技术亮点：极简仓库，Python 脚本 + 标准化 marketplace.json / plugin.json manifest 完成索引。一条 /plugin marketplace add anthropics/claude-plugins-official 即挂载整个目录；价值在治理与收录权而非代码量。
  • 适用场景：Claude Code 用户装可信插件；研究官方插件目录结构；把自家插件提交进官方收录。
  • 关键数据：语言 Python；Stars 27,173；Today Stars +1,179；Forks 2,898；License —；最近更新 2026-05-24；Topics：claude-code、mcp、skills；Homepage：https://code.claude.com/docs/en/plugins

4. anthropics/knowledge-work-plugins

  • 项目简介：Open source repository of plugins primarily intended for knowledge workers to use in Claude Cowork
  • 为什么火：今日 +486 stars，Anthropic 第二个官方插件仓库登榜。和 claude-plugins-official 的「开发者插件」错位，这套面向知识工作者，配合 Claude Cowork 使用，象征 Claude 生态从 Coding Agent 向 Office/Knowledge Worker 平台扩张。
  • 技术亮点：Apache-2.0 开源，Python 实现。围绕 Claude Cowork 场景给出整套 plugin/skill 范式：文档处理、研究助理、知识沉淀、跨部门协作。manifest 与开发者插件目录同构，方便企业内部 fork 出私有插件源。
  • 适用场景：用 Claude Cowork 做内部知识管理的团队；产品/咨询/法务等非工程角色的 AI 助理改造；想做企业版插件目录的中台。
  • 关键数据：语言 Python；Stars 13,844；Today Stars +486；Forks 1,715；License Apache-2.0；最近更新 2026-05-24；Topics：暂无；Homepage：—

5. multica-ai/andrej-karpathy-skills

  • 项目简介：A single CLAUDE.md file to improve Claude Code behavior, derived from Andrej Karpathy’s observations on LLM coding pitfalls.
  • 为什么火：+2,555 stars 仍在榜中段，累计 star 量已破 15 万。一份 CLAUDE.md 把 Karpathy 关于 LLM 编程陷阱的观察直接注入 Claude Code，是「最小成本提升 Agent 输出质量」的最快路径，因此被疯狂收藏。
  • 技术亮点：本质是 prompt/上下文工程：把 Karpathy 公开发言中的 LLM 编码经验整理成结构化的 CLAUDE.md，覆盖代码风格、错误处理、调试纪律、注释规范等几十条 do/don’t，直接放进项目根目录就能立刻生效。
  • 适用场景：想快速拉高 Claude Code 输出质量的所有项目；团队约定统一编码风格；做内部 CLAUDE.md / AGENTS.md 模板的起点。
  • 关键数据：语言 —；Stars 151,788；Today Stars +2,555；Forks 15,568；License —；最近更新 2026-04-20；Topics：暂无；Homepage：—

6. earendil-works/pi

  • 项目简介：AI agent toolkit: coding agent CLI, unified LLM API, TUI & web UI libraries, Slack bot, vLLM pods
  • 为什么火：今日 +444 stars。在 Claude Code / Codex / Cursor 之外，一个开源的「AI agent toolkit」全家桶冒头——CLI、统一 LLM API、TUI/Web UI 库、Slack bot、vLLM pods 一次给齐，瞄准想自建 Agent 平台的团队。
  • 技术亮点：TypeScript 实现，MIT 协议。统一 LLM API 抽象封装多家模型；自带 TUI 和 Web UI 组件库；附带 Slack 机器人与 vLLM 推理 pod 调度模板，相当于把 Agent 平台的「胶水层」开源了一遍。
  • 适用场景：想做内部 Coding Agent 但不愿被单一厂商绑定的团队；自建 LLM 网关 + Agent UI 的中台项目；vLLM 私有化部署 + Slack 工作流的组合。
  • 关键数据：语言 TypeScript；Stars 53,840；Today Stars +444；Forks 6,430；License MIT；最近更新 2026-05-24；Topics：暂无；Homepage：—

7. Alishahryar1/free-claude-code

  • 项目简介：Use claude-code for free in the terminal, VSCode extension or discord like OpenClaw (voice supported)
  • 为什么火：+557 stars 冲入前十。名字直白——「免费用 claude-code」，结合终端、VSCode 扩展和 Discord 三端，蹭住了订阅价格焦虑和 OpenClaw 类语音 Agent 的热度，自然吸睛。
  • 技术亮点：Python 实现，MIT 协议。在终端、VSCode 扩展和 Discord 三端复刻 Claude Code 体验，并明确支持语音交互（README 类比 OpenClaw）。本质是给非订阅用户提供等价的 Agent CLI 包装，靠社区 key 池/转发实现「免费」。
  • 适用场景：想低成本体验 Claude Code 工作流的个人开发者；Discord 社区里的 AI 协作机器人；语音驱动 Coding Agent 的玩家。
  • 注意事项：项目以「免费使用 claude-code」为卖点，背后通常涉及共享/中转 key，生产环境慎用，注意数据合规与服务条款。
  • 关键数据：语言 Python；Stars 29,066；Today Stars +557；Forks 4,364；License MIT；最近更新 2026-05-24；Topics：暂无；Homepage：—

8. colbymchenry/codegraph

  • 项目简介：Pre-indexed code knowledge graph for Claude Code, Codex, Cursor, OpenCode, and Hermes Agent — fewer tokens, fewer tool calls, 100% local
  • 为什么火：今日 +2,993 stars，再次冲到榜单前列。和榜首 Understand-Anything 形成镜像——一个偏团队可视化解读，一个偏 Agent 可检索上下文压缩。两个项目同时火，说明「代码即图」已是 2026 年的共识。
  • 技术亮点：TypeScript 实现，把符号、调用、依赖、文件关系预索引成图。Agent 不再做盲读全仓 read_file，而是按节点拉最小上下文。提供预编译二进制，无需 Node 环境直接跑，企业落地友好。
  • 适用场景：中大型代码库接 AI 编辑器；想压低月度 token 成本的工程团队；本地隐私优先、不能上云的部门。
  • 关键数据：语言 TypeScript；Stars 21,701；Today Stars +2,993；Forks 1,208；License MIT；最近更新 2026-05-24；Topics：暂无；Homepage：https://colbymchenry.github.io/codegraph/

9. multica-ai/multica

  • 项目简介：The open-source managed agents platform. Turn coding agents into real teammates — assign tasks, track progress, compound skills.
  • 为什么火：今日 +584 stars。多家「Coding Agent 管理平台」赛道里的新选手——把 Claude Code/Codex 这类 Agent 当成真正的「团队成员」管理：任务分派、进度跟踪、技能复用，瞄准的是 Agent 工程化运营。
  • 技术亮点：TypeScript 全栈，open-source managed agents 平台。围绕「任务-Agent-技能」三元组建模：把多个 Coding Agent 注册成可调度的工作者，提供 dashboard 跟踪进度、累积可复用技能（skills 复用思想与 Anthropic 官方插件同源）。
  • 适用场景：已经在团队内用 Claude Code 的研发组织；做 AI Ops 的中台团队；想做内部 Agent SaaS 的初创公司。
  • 关键数据：语言 TypeScript；Stars 32,394；Today Stars +584；Forks 3,898；License Custom / NOASSERTION；最近更新 2026-05-24；Topics：暂无；Homepage：https://multica.ai

10. shiyu-coder/Kronos

  • 项目简介：Kronos: A Foundation Model for the Language of Financial Markets
  • 为什么火：+96 stars 收尾。在清一色 AI Coding/Agent 项目中，唯一一个金融基础模型项目登榜——金融市场的「语言模型」概念再次出圈，配合最近量化研究热度，吃到了垂直领域关注。
  • 技术亮点：Python 实现，MIT 协议。把金融市场行为（成交、订单流、价格序列等）建模成一种「语言」，训练 foundation model，目标是给量化策略、风险评估、做市等下游任务提供统一表示，思路上对标 NLP 的 BERT/GPT 路线。
  • 适用场景：量化研究员探索基础模型路线；做金融时序预测 / 异常检测的团队；学界与业界做 finance foundation model 实验的起点。
