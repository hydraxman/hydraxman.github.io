今天的 GitHub Trending Daily 是一份“Agent 工程层 + 久违的老朋友”的混合榜单：榜单前 7 个项目里有 5 个直接服务 AI 编码 Agent——Anthropic 官方插件目录继续屠榜、codegraph 单日再爆 +3,688、Chrome DevTools 官方 MCP、.NET 官方 Skills、Lum1104 的多语言知识图谱 Understand-Anything，连 AI 工程课程 ai-engineering-from-scratch 也在被工程师集体补课。

非 Agent 阵营这次给了三个非常不一样的信号：ruvnet/RuView 把 WiFi 信号变成隔墙感知/呼吸心率监测，是“无摄像头空间感知”第一次大规模出圈；odoo 这位开源 ERP 老将在 AI 业务集成浪潮里被重新翻出来当沙箱；trimstray 的工程师秘籍合集再次冲榜，说明每隔几个月就有新一批人在补基础。最后一个 byJoey/cfnew 则代表中文社区对“可视化无服务器代理”的长期刚需。

1. anthropics/claude-plugins-official

  • 项目简介：Anthropic 官方维护的 Claude Code 插件目录 (Marketplace)，集中收录通过审核的高质量插件——agents、skills、commands、hooks、output styles、MCP servers 一站式索引。
  • 为什么火：今天 +2,556 stars，连续两天稳坐榜首。第三方插件野蛮生长之后，Anthropic 终于把“可信插件”这件事收回官方，相当于 Claude Code 的“App Store 心智”正式坐实——开发者愿意下注 Claude 生态的最强信号。
  • 技术亮点：仓库本身极简：Python 脚本 + 一份标准化的 marketplace.json / plugin.json manifest。Claude Code 用户一条命令 /plugin marketplace add anthropics/claude-plugins-official 就能挂载整个目录，价值不在代码量，在“治理 + 收录权”。
  • 适用场景：想给 Claude Code 装可信插件、研究官方插件目录结构、或者写了自己的插件希望被官方收录的开发者。
  • 关键数据：语言 Python；Stars 24,593；Today Stars +2,556；Forks 2,749；License —；最近更新 2026-05-22；Topics：claude-code, mcp, skills；Homepage：https://code.claude.com/docs/en/plugins

2. colbymchenry/codegraph

  • 项目简介：面向 Claude Code、Cursor、Codex、OpenCode、Hermes Agent 的“预索引代码知识图谱”，主打 35% 更便宜、70% 更少工具调用、100% 本地。
  • 为什么火：单日 +3,688 stars 蝉联榜单第二。所有 Coding Agent 现在的共同痛点都是 token 账单和盲目 grep；codegraph 把“先建图，再让 Agent 按节点取上下文”这个公认收敛方向做成了开箱即用的本地工具，正好踩在所有 AI 编辑器的命门上。
  • 技术亮点：TypeScript 实现的本地代码知识图谱：把符号、调用关系、依赖结构预索引成可检索的图，Agent 不再做盲读全仓 read_file，而是按节点精确取最小相关上下文。属于 RAG-on-codebase 的图结构升级版，且无需 Node.js 环境，预编译二进制直接跑。
  • 适用场景：大型/中等代码库接入 AI 编辑器；想压低月度 token 成本的工程团队；本地隐私优先、不能把代码上云的部门。
  • 关键数据：语言 TypeScript；Stars 16,269；Today Stars +3,688；Forks 893；License MIT；最近更新 2026-05-22；Topics：暂无公开 topics；Homepage：—

3. ruvnet/RuView

  • 项目简介：把普通 WiFi 信号变成实时空间感知系统——可以隔墙检测人员、测量呼吸和心率、追踪移动、监控房间，无需任何摄像头或可穿戴设备。
  • 为什么火：今天 +992 stars，总 Stars 已经 6 万+，是“WiFi 感知”这个学术方向第一次大规模出圈的开源项目。叠加 ESP32 硬件普及和居家健康监测刚需，让“无摄像头的环境感知”从论文走到了开发者周末项目层面。
  • 技术亮点：Rust 实现，基于 ESP32 (S3/C6/P4 等双核+) 提取 WiFi CSI (Channel State Information)，做 DSP + 姿态估计推断。仓库自己也坦诚标注是 Beta 软件：单节点空间分辨率有限、当前 PCK@20 精度仅 ~2.5%（用 proxy label 训练），需要 2+ 节点或 Cognitum Seed 才能获得较好效果，相机监督训练目标 35%+ 仍在数据收集阶段。
  • 适用场景：智能家居、独居老人/婴幼儿呼吸心率监测、无人值守门店人流统计、低成本物理空间感知研究。需要明确：这是研究级 Beta，不是消费级成品。
  • 关键数据：语言 Rust；Stars 63,870；Today Stars +992；Forks 8,442；License MIT；最近更新 2026-05-22；Topics：agentic-ai, densepose, esp32, firmware, mcu, mincut, monitoring, pose-estimation, rf, self, self-learning, spatial-intelligence, wifi, wifi-hacking, wifi-security, world-model；Homepage：https://Cognitum.One/RuView

4. rohitg00/ai-engineering-from-scratch

  • 项目简介：一套面向工程师的 AI Engineering 课程仓库——20 个阶段、435 节课、约 320 小时，覆盖 Python/TypeScript/Rust/Julia，每节课都附可运行的小项目。
  • 为什么火：今天 +988 stars。市面上“AI 课程”多到泛滥，但绝大多数停在“调用 ChatGPT API + LangChain Demo”。这个仓库少见地把课程做成“从零写引擎”——分词、embedding、向量检索、模型推理、Agent 编排一路自己实现，正好填了“想看懂底层而非只会调用”的空缺。
  • 技术亮点：纯教学型仓库：每个 phase 一个目录，按依赖关系递进，附 ROADMAP + 课程网站 aiengineeringfromscratch.com。Banner 和 README 是 SVG/ASCII 风格，强调“lessons-435 / phases-20”作为完成度承诺。本质是“可读教材 + 可跑代码”的合集，不是框架。
  • 适用场景：想系统补 AI 工程基础的应用开发者；准备 AI 方向跳槽/转岗的工程师；做技术内训需要现成大纲的团队 Lead。
  • 关键数据：语言 Python；Stars 11,685；Today Stars +988；Forks 2,224；License MIT；最近更新 2026-05-22；Topics：agents, ai, ai-agents, ai-engineering, computer-vision, course, deep-learning, from-scratch, generative-ai, llm, machine-learning, mcp, nlp, python, reinforcement-learning, rust, swarm-intelligence, transformers, tutorial, typescript；Homepage：https://aiengineeringfromscratch.com

5. ChromeDevTools/chrome-devtools-mcp

  • 项目简介：Google Chrome DevTools 团队官方出品的 MCP (Model Context Protocol) Server，把整套 DevTools 能力——网络面板、性能面板、控制台、DOM、协议追踪——直接暴露给编码 Agent。
  • 为什么火：今天 +499 stars，总 Stars 已经 4 万+，长期占榜。这是 Chrome 团队首次官方承认“AI Agent 是 DevTools 的一等公民”——以前 Agent 调试网页只能各自封 Puppeteer/Playwright，现在 Chrome 自己出来定标准。MCP 协议拿到第一个一线浏览器厂商背书，意义远大于代码本身。
  • 技术亮点：TypeScript 写的 MCP Server，底层走 Chrome DevTools Protocol (CDP) 接管真实 Chrome/Chromium 实例。Agent 通过 MCP 工具调用拿到的是结构化 DOM、网络瀑布、性能 trace、Console 日志，而不是截图后做 OCR。可以理解成给 Claude/Cursor/Codex 装了一双能“看见浏览器内部”的眼睛。
  • 适用场景：Web 应用调试与性能分析、前端 bug 复现、自动化 e2e 测试断言、做 AI 浏览器 Agent 时绕开 Puppeteer 自己造轮子。
  • 关键数据：语言 TypeScript；Stars 40,913；Today Stars +499；Forks 2,595；License Apache-2.0；最近更新 2026-05-22；Topics：browser, chrome, chrome-devtools, debugging, devtools, mcp, mcp-server, puppeteer；Homepage：https://npmjs.org/package/chrome-devtools-mcp

6. dotnet/skills

  • 项目简介：.NET 官方仓库出品的 Claude Code Skills 包，专门给 AI 编码助手写 .NET / C# 代码用——CLI、模板、调试、单测、ASP.NET、Blazor、MAUI 覆盖全套。
  • 为什么火：今天 +391 stars，总 Stars 才 2,485 但增速健康。这件事的真正信号不在 star 数，而在“微软 .NET 官方团队亲自下场写 Claude Code Skills”——意味着大厂已经把“在 AI Agent 里占座”当作语言生态战略的一部分，未来其他官方语言/框架 Skill 包会成为标配。
  • 技术亮点：严格按 Anthropic Skills 规范组织：每个 skill 一个目录、一份 SKILL.md，配套 references / scripts，触发条件、步骤、pitfalls、verification 一应俱全。这是给 Agent 的“官方手册”，不是给人读的 Markdown 教程。
  • 适用场景：用 Claude Code 写 .NET/C# 后端、ASP.NET API、Blazor 前端、MAUI 跨平台的团队，可以直接挂载，省掉自己积累 .NET 工程惯例的过程。
  • 关键数据：语言 **C#**；Stars 2,485；Today Stars +391；Forks 196；License MIT；最近更新 2026-05-22；Topics：agent-skills；Homepage：—

7. Lum1104/Understand-Anything

  • 项目简介：“把任何代码库、知识库、文档变成可交互的知识图谱”——支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等主流 AI 编程工具一键查询和探索。
  • 为什么火：今天 +1,391 stars，总 Stars 1.8 万+。和今天的 codegraph 撞在同一个赛道——RAG-on-codebase 的图结构方案。区别在于它不只盯代码：文档、Wiki、产品知识库都能塞进同一张图，更偏“知识库通用化”，加上多语言 README (含中文/日语/韩语等 7 种) 直接打到全球开发者社区。
  • 技术亮点：TypeScript 主体，把目标仓库或文档解析成节点+边的图结构，搭配 Web UI 可视化探索；Agent 端通过工具调用按节点拉上下文，对话窗口里能直接问“这个函数被谁调用、这个 API 的 RFC 怎么定义”。把交互式探索做成第一公民，比纯 CLI 的图谱更适合产品/技术混合团队。
  • 适用场景：中大型代码库的新人 onboarding、跨团队知识库共享、技术 PM 想看懂模块依赖、AI 编辑器接入企业内部 wiki。
  • 关键数据：语言 TypeScript；Stars 18,272；Today Stars +1,391；Forks 1,654；License MIT；最近更新 2026-05-22；Topics：antigravity-skills, business-knowledge, claude-code, claude-skills, codebase-analysis, codex, codex-skills, developer-tools-ai-agent, gemini-cli-skills, karpathy-llm-wiki, knowledge-base, knowledge-graph, memory, opencode-skills, pi-agent, understandcode, vibe-coding；Homepage：https://understand-anything.com

8. odoo/odoo

  • 项目简介：全球用户量最大的开源企业管理 (ERP) 平台之一，覆盖 CRM、电商、会计、库存、HR、制造、项目管理等几十个业务模块。
  • 为什么火：今天 +48 stars 算“小幅波动”，但总 Stars 5.1 万 + Forks 几万、长期是中小企业自建 ERP 的事实标准。今天能进榜更像“老牌选手的稳定回潮”——AI Agent 浪潮里所有人都在补企业系统集成，Odoo 这种带完整业务对象的开源 ERP 又被翻出来当“给 Agent 操作的真实业务沙箱”。
  • 技术亮点：Python (后端) + JavaScript (前端 OWL 框架) + PostgreSQL，模块化插件架构 (addons/)，每个业务模块独立可装可卸；社区版 (CE) 完全开源，企业版 (EE) 走双授权。代码体量巨大但分层清晰，是“怎么写一个被几十万家公司跑在生产的开源 ERP”的活教材。
  • 适用场景：中小企业自建 ERP 替代 SAP/Oracle；二开商；学 Python 大型业务系统架构；最近一年也常被作为 LLM 业务流程 Agent 的演练沙箱。
  • 关键数据：语言 Python；Stars 51,072；Today Stars +48；Forks 32,513；License NOASSERTION；最近更新 2026-05-22；Topics：apps, business, erp, management, odoo, odoo-apps, python；Homepage：https://www.odoo.com

9. byJoey/cfnew

  • 项目简介：Cloudflare Workers / Pages 上跑的多协议代理网关“终端”，支持 VLESS、Trojan、xhttp 等多协议同时启用，图形化管理后台、KV 存配置、订阅一键转换。
  • 为什么火：今天 +85 stars，靠中文社区口碑长期上榜。这一类基于 Cloudflare 边缘节点的“无服务器代理”项目在中文圈是刚需，cfnew 把多协议、可视化、订阅转换、客户端唤醒一次性打包，比早期只能命令行配置的方案对小白友好太多。
  • 技术亮点：运行在 Cloudflare Workers/Pages，配置存 KV，热生效无需重新部署；后台可通过 API 动态增删优选 IP，前端按 User-Agent 自动返回 Clash / Surge / Sing-Box / Loon / Quantumult X / V2Ray / Shadowrocket 等不同客户端格式。多语言 + 应用唤醒按钮把使用门槛压到接近“一键”。
  • 适用场景：需要自建轻量代理、做订阅聚合、给非技术家人朋友配上网工具的中文用户。注意：合规边界请自行把握，仓库定位是技术工具。
  • 关键数据：语言 —；Stars 13,281；Today Stars +85；Forks 6,476；License —；最近更新 2026-05-22；Topics：暂无公开 topics；Homepage：—

10. trimstray/the-book-of-secret-knowledge

  • 项目简介：GitHub 上规模最大的“工程师私藏宝典”资源合集之一——总 Stars 22 万+，按主题收录 CLI 工具、安全清单、网络/Linux/性能调优、运维实战脚本、各类速查表和论文。
  • 为什么火：今天 +964 stars。这本“秘籍”几乎每隔几个月就会因为新一波工程师集体补课重新冲榜，长寿到不像 trending 项目。能持续被收藏，本质是它扮演了“工程师私人 Notion 的开源公约数”：你想找的工具/技巧大概率有人替你整理好了。
  • 技术亮点：纯 Markdown 仓库，没有任何代码——价值全在分类、链接和注释的密度。按 “Tools / CLI / Networking / Web servers / Databases / Pentesting / Performance / Books” 等大类组织，每个条目都给一句话点评。
  • 适用场景：运维/SRE/安全工程师当 daily reference；新人补 Linux/网络/CLI 基础；面试前回炉；建团队内部 wiki 时找现成索引。
  • 关键数据：语言 —；Stars 223,106；Today Stars +964；Forks 13,379；License MIT；最近更新 2024-11-19；Topics：awesome, awesome-list, bsd, cheatsheets, devops, guidelines, hacking, hacks, howtos, linux, lists, manuals, one-liners, pentesters, resources, search-engines, security, security-researchers, sysops；Homepage：—

一句话总结

  • Agent 工程层继续补课：插件目录治理 (claude-plugins-official)、代码知识图谱 (codegraph / Understand-Anything)、官方语言 Skill (dotnet/skills)、浏览器 MCP (chrome-devtools-mcp) 同日上榜，说明模型层没新爆点，社区把精力全砸在“怎么让 Agent 真正能干活”。
  • WiFi 感知首次破圈：RuView 把研究级 CSI 感知做成可复现的 ESP32 开源项目，是消费级硬件 + 物理感知第一次进入主流 trending 视野，虽然仍是 Beta，方向值得关注。
  • 老牌项目周期回潮：odoo、the-book-of-secret-knowledge 这类长寿仓库再次上榜，往往不是项目本身有大新闻，而是新一批工程师/团队又开始补基础。
