今天 GitHub 热榜的信号：AI 开始给自己装护栏，也开始反感千篇一律

今天这份榜单最有意思的，不是 AI 项目又占了几席，而是开发者正在补上 AI 落地后暴露出的两块短板：一块是安全，另一块是审美。有人给编程 Agent 加“保险丝”，有人专门拦截 AI 最爱生成的模板化界面。

另一条线也很清楚：开源视频剪辑、设计协作、Windows 清理和健身数据集都在升温。大家追的已经不只是更聪明的模型，而是能直接拿来干活、还能保留控制权的工具。

1. Shubhamsaboo / awesome-llm-apps

  • 项目简介： 收录 100 多个可运行的 AI Agent、RAG 应用与 Agent Skill，覆盖主流闭源和开源模型。
  • 为什么火： 它把“看懂一个案例”缩短成“克隆、填 API Key、直接跑”，很适合需要快速验证产品想法的开发者；单日新增 1,104 Stars 说明模板型生产资料仍有旺盛需求。
  • 技术亮点： 示例按场景拆分，提供单文件入门 Agent、RAG 应用和可安装技能；技能还强调安全与评测检查，比只堆 Prompt 的清单更接近工程起点。
  • 适用场景： Agent 原型、RAG 产品验证、教学演示、团队内部技术选型。项目很多，质量和依赖并不可能完全一致，上生产前仍要逐个审计。
  • 关键数据： Python｜120,633 Stars｜今日 +1,104｜17,861 Forks｜Apache-2.0｜最近更新 2026-07-14｜Topics：agents、llms、python、rag。

2. mattpocock / skills

  • 项目简介： 一套从真实工程实践中整理出的 Agent Skills，主张“小而可组合”，而不是让一套庞大流程接管整个开发过程。
  • 为什么火： 编程 Agent 普及后，开发者开始关心如何复用自己的工程习惯。它一天增加 1,864 Stars，踩中的正是“保留人的控制权，同时让 Agent 少走弯路”这个痛点。
  • 技术亮点： 支持按需安装、项目内修改，也提供 Claude Code 插件式订阅；设置流程可接 GitHub、Linear 或本地文件，把技能真正嵌进工单与文档链路。
  • 适用场景： 需求拆解、工单分诊、工程文档、代码 Agent 工作流标准化。它不是全自动开发框架，价值取决于团队是否愿意维护自己的规则。
  • 关键数据： Shell｜170,023 Stars｜今日 +1,864｜14,632 Forks｜MIT｜最近更新 2026-07-14。

3. Dicklesworthstone / destructive_command_guard

  • 项目简介： 一道放在 AI 编程工具与终端之间的安全闸门，在危险的 Git 或 Shell 命令真正执行前将其拦下。
  • 为什么火： Agent 权限越来越大，“删错目录”不再只是人的手滑。这个项目把抽象的 AI 安全变成一条能立即安装的保险丝，今日新增 481 Stars。
  • 技术亮点： Rust 编写，适配 Claude Code、Codex CLI、Gemini CLI、Copilot CLI、Cursor、Hermes Agent 等多种工具，并通过各家的 Hook 机制统一阻断高风险操作。
  • 适用场景： 允许 Agent 操作代码仓库、终端或 CI 环境的个人与团队。它能挡住已识别的危险模式，但不能替代最小权限、备份和代码审查。
  • 关键数据： Rust｜4,308 Stars｜今日 +481｜163 Forks｜许可证未标准声明｜最近更新 2026-07-13｜Topics：ai-agents、cli、developer-tools、git、safety。

4. OpenCut-app / OpenCut

  • 项目简介： 免费开源的视频编辑器，目标是覆盖浏览器、桌面和移动端，直接挑战封闭的视频剪辑平台。
  • 为什么火： 今日 +4,349 Stars 是榜单最高增量。创作者既想要熟悉的时间线体验，也不想把素材、工作流和插件能力锁在单一平台里。
  • 技术亮点： 新架构规划使用一套 Rust 核心支撑多端，强调插件优先、无头批量渲染和编辑器内脚本能力，方向比“复刻一个网页剪辑器”更有野心。
  • 适用场景： 开源视频剪辑、私有化创作工具、自动化批量渲染。要注意：项目正在重写，当前稳定体验仍指向 classic 版本，且新架构暂未开放外部贡献。
  • 关键数据： TypeScript｜68,996 Stars｜今日 +4,349｜7,195 Forks｜MIT｜最近更新 2026-07-10｜Topics：editor、oss、videoeditor。

5. virattt / ai-hedge-fund

  • 项目简介： 用多个投资人格 Agent 分工研究、估值和风控的概念验证项目，模拟从格雷厄姆到塔勒布等不同投资方法。
  • 为什么火： 多 Agent 最容易被理解的演示之一，就是让不同角色公开“辩论”一只股票。61,813 Stars 说明它同时吸引了 AI 开发者和量化爱好者。
  • 技术亮点： 将投资流派拆成可组合角色，并计划把它们改造成可回测的 alpha 模型，逐步加入持续运行、模拟交易与可选实盘能力。
  • 适用场景： 多 Agent 编排教学、投研流程原型、回测实验。仓库明确声明仅用于教育；名人式人格输出不等于可验证的投资优势，更不能当作交易建议。
  • 关键数据： Python｜61,813 Stars｜今日 +156｜10,907 Forks｜MIT｜最近更新 2026-07-10。

6. Nutlope / hallmark

  • 项目简介： 给 Claude Code、Cursor 和 Codex 使用的设计技能，目标很直接：别再生成一眼就能认出的“AI 模板站”。
  • 为什么火： 当渐变大标题、玻璃卡片和三栏功能区变成默认答案，审美同质化本身就成了新痛点。Hallmark 今日增加 1,010 Stars，说明开发者已经开始给 AI 建立视觉品控线。
  • 技术亮点： 根据 brief 选择宏观版式和 20 种主题，设置 57 项模板化痕迹检查与输出前自评；还支持审计、重设计和提取参考设计“DNA”。
  • 适用场景： 落地页、品牌站、现有前端审美审计、设计方向探索。规则能减少套路，但不能替代品牌策略、用户研究和专业设计师的取舍。
  • 关键数据： CSS｜6,009 Stars｜今日 +1,010｜348 Forks｜MIT｜最近更新 2026-06-26。

7. HKUDS / Vibe-Trading

  • 项目简介： 香港大学数据智能实验室推出的个人交易 Agent，把行情获取、研究、回测和工具调用放进一套工作流。
  • 为什么火： “一句话让 Agent 做投研”足够有吸引力，而影子账户、回测与 MCP 接口又让它比普通金融聊天机器人更接近可操作系统，今日新增 1,265 Stars。
  • 技术亮点： 支持多数据源切换与完整性检查，提供 MCP 的 Streamable HTTP 传输，并持续补齐中国市场数据、模型供应商和配置可靠性。
  • 适用场景： 个人量化研究、行情分析、Agent 工具调用实验和模拟账户验证。金融数据有延迟和缺口，策略回测也可能过拟合，接入真实资金前必须独立风控。
  • 关键数据： Python｜22,729 Stars｜今日 +1,265｜3,904 Forks｜MIT｜最近更新 2026-07-14｜Topics：ai-agent、algorithmic-trading、backtesting、fintech、llm、mcp。

8. Raphire / Win11Debloat

  • 项目简介： 一款轻量 PowerShell 工具，用来批量移除 Windows 预装应用、关闭遥测、清理界面干扰项并统一个性化设置。
  • 为什么火： 它解决的是一个多年不变的真实痛点：新装系统后逐项关闭干扰设置太费时间。今日 +779 Stars，也说明“把控制权还给用户”的工具依然有生命力。
  • 技术亮点： 无需安装，既有交互式流程也有命令行参数；支持审计模式、修改其他用户配置，以及导入导出设置，方便多台机器复用。
  • 适用场景： 个人电脑整理、批量装机、系统管理员标准化配置。删除系统组件存在兼容风险，执行前应看清选项并保留恢复手段。
  • 关键数据： PowerShell｜51,499 Stars｜今日 +779｜2,116 Forks｜MIT｜最近更新 2026-07-14｜Topics：bloatware、cleanup、cli、debloat。

9. hasaneyldrm / exercises-dataset

  • 项目简介： 一套可直接接入应用的健身动作数据集，包含 1,324 个动作、GIF、缩略图、器械与肌群字段，以及多语言步骤说明。
  • 为什么火： 对健身应用而言，最耗时间的往往不是页面，而是整理一套结构统一、带媒体素材的数据层。今日 +864 Stars，反映了“即插即用数据资产”的稀缺。
  • 技术亮点： 每个动作都有分类、目标肌群、器械和步骤化说明，并附交互浏览器与开发者设置页面；README 当前列出 9 种语言支持。
  • 适用场景： 健身 App、训练计划、动作推荐、教育演示与机器学习原型。媒体素材有单独版权说明，商用前不能只看仓库代码许可。
  • 关键数据： HTML｜13,331 Stars｜今日 +864｜1,580 Forks｜许可证未标准声明｜最近更新 2026-07-09｜Topics：dataset、exercise-database、fitness、gym。

10. penpot / penpot

  • 项目简介： 面向产品团队的开源设计协作平台，可在浏览器使用，也能自托管在企业自己的基础设施上。
  • 为什么火： 当设计文件、协作数据和插件生态都关系到长期成本，开源与自托管就不只是情怀。Penpot 今日新增 264 Stars，靠的是成熟产品与持续迭代，而不是短期噱头。
  • 技术亮点： 以 SVG、CSS、HTML、JSON 等开放标准表达设计，支持设计令牌、实时协作、API、插件与 MCP；Grid 和 Flex 布局让设计结果更接近真实前端结构。
  • 适用场景： 产品设计、设计系统、设计开发协作、合规要求较高的私有部署。迁移现有团队仍会遇到插件、文件兼容和协作习惯成本。
  • 关键数据： Clojure｜56,076 Stars｜今日 +264｜3,691 Forks｜MPL-2.0｜最近更新 2026-07-14｜Topics：design、prototyping、ui、ux-design、clojure。

今天真正值得看的，不只是 AI

OpenCut、Win11Debloat、健身数据集和 Penpot 同时上榜，提醒了一个容易被 AI 热潮遮住的事实：开源项目最终还是要靠具体问题活下来。 Agent Skills、命令护栏和设计反套路工具，则说明 AI 工程已经进入第二阶段——不只追求“能做”，还要解决“别闯祸”和“别都长一个样”。

热榜每天都在换，但能留下来的，从来不是最会追热点的项目，而是把一个真实麻烦解决得足够彻底的项目。
