今天的 GitHub Trending 像一张完整的 AI 工具链地图：榜首 gods-eye-view 把航空、航运、卫星和地震等公开信号叠进 3D 地球；随后出现的提示词库、架构图工具、插件目录、科学 Skill 与视频系统，则在把模型能力包装成可安装、可复用的生产组件。

单日增量最高的 Archify 新增 4,260 Stars，awesome-gpt-image-2 增加 2,093 Stars，gods-eye-view 增加 1,984 Stars。Nitter 只增加 63 Stars，却排到第二；项目在 README 顶部声明，X Corp 已于 8 月 24 日发函要求永久下架实例与仓库。今天的榜单既有 Agent 工作流升温，也有隐私前端与平台控制权的现实冲突。

1. bilawalsidhu/gods-eye-view

  • 项目简介： God’s Eye View 是运行在浏览器里的空间情报可视化工具。它把航班、船舶、卫星、地震、交通、火情和公共摄像头等公开信号叠到写实 3D 地球上，并提供驾驶舱、轨迹追踪、传感器滤镜和语音控制。
  • 为什么火： 传统 OSINT 往往散落在多个网页和数据面板里，这个项目把信号变成可以搜索、跟踪和分享的空间界面。项目还承接了作者公开视频系列的传播势能，今天增加 1,984 Stars。
  • 技术亮点： 地图层使用 Google Photorealistic 3D、Bing 航拍和 OSM，实时数据来自 OpenSky、adsb.lol、AISStream、CelesTrak、USGS 等公开服务。每个图层会标明数据的新鲜度，以及延迟、模拟、估算或不可用状态；语音 Agent 可读取当前坐标、视野和已选对象后调用 28 个工具。
  • 适用场景： 适合 OSINT 教学、航空航运观察、空间数据演示和交互式新闻可视化。Google Maps Key 是必需项，部分数据源与语音能力需要额外密钥；MIT 只覆盖源码，第三方数据、3D 模型和商业使用条件必须分别核对。
  • 关键数据： JavaScript｜Stars 7,416｜Today +1,984｜Forks 1,726｜License MIT（代码；数据/资产另有许可）｜最近更新 2026-08-27｜Topics：3D Globe、OSINT、GIS、Flight Tracking。

2. zedeus/nitter

  • 项目简介： Nitter 是面向 X/Twitter 的自由开源前端，页面没有广告和客户端 JavaScript，所有请求由后端转发。用户可以阅读公开内容、订阅 RSS，并避免把 IP 与浏览器指纹直接交给平台。
  • 为什么火： 项目在 README 顶部声明，X Corp 于 2026 年 8 月 24 日发出停止侵权函，要求永久下架 Nitter 实例与仓库。它今天只增加 63 Stars，上榜更像是平台控制权与隐私替代前端再次进入开发者视野，而非突然出现的产品增长。
  • 技术亮点： Nitter 使用 Nim 构建，依赖 Redis 或 Valkey 缓存，并通过 X/Twitter 的非官方接口获取内容。README 给出的示例页面约为 60KB，对应官方页面约 784KB；时间线通常可快 2—4 倍。
  • 适用场景： 适合愿意自托管、需要 RSS 或无 JavaScript 阅读体验的个人和社区。非官方接口会随上游变化而失效，部署还需要反向代理与缓存服务；当前法律压力也使公共实例和仓库的连续性存在明显风险。
  • 关键数据： Nim｜Stars 13,801｜Today +63｜Forks 1,110｜License AGPL-3.0｜最近更新 2026-08-26｜Topics：Privacy、Self-hosted、Twitter、X。

3. freestylefly/awesome-gpt-image-2

  • 项目简介： 这是一套面向 GPT Image 2 的 Prompt-as-Code 资产库，收录 530 多个案例、20 多套模板、分类画廊和可安装的 Agent Skill。它把零散提示词整理成可检索、可维护、可组合的视觉生产资料。
  • 为什么火： 图像模型已经能做出高质量单张作品，内容团队更难的是稳定风格、批量复用和跨工具分发。项目把这部分经验直接做成模板与 Skill，今天增加 2,093 Stars。
  • 技术亮点： 网站、分类数据、模板和 Agent Skill 共用同一套结构化资产，Agent 可以按风格、场景与用途检索，再把选中的方向拼进任务提示。仓库还提供 CLI 与多种 Agent 的安装入口，方便在团队工作流中同步。
  • 适用场景： 适合文章配图、电商素材、社交海报、知识图和需要系列视觉一致性的内容团队。模板能缩小搜索空间，却不能消除模型版本、参考图、随机性和生成参数带来的差异，重要文本与数字仍需要单独验收。
  • 关键数据： JavaScript｜Stars 22,905｜Today +2,093｜Forks 2,280｜License MIT｜最近更新 2026-08-26｜Topics：GPT Image 2、Prompt as Code、Agent Skills、AI Image Generation。

4. tt-a1i/archify

  • 项目简介： Archify 是给 Coding Agent 使用的技术制图 Skill，可生成架构、工作流、时序、数据流和生命周期图。交付物是带搜索、路径追踪、主题切换和导出能力的单文件 HTML，也能输出 PNG、SVG 与分享卡。
  • 为什么火： 它今天增加 4,260 Stars，是榜单单日增量最高的项目。Agent 已经很会读代码，但把系统关系讲清楚仍费时间；Archify 把“画图”推进到可验证中间表示、可定位错误和版本差异对比。
  • 技术亮点： Agent 先生成带类型的 JSON IR，再执行 Schema、布局、标签和线路检查；候选结果全部通过后才原子替换旧文件。Architecture Delta 还能比较 Before、Delta 与 After，机器回执会列出新增、删除、移动、修改和改线的事实。
  • 适用场景： 适合架构评审、PR 说明、系统交接、数据链路和 Agent 工作流展示。它验证的是写进图里的事实，不会自动证明线上基础设施与图一致；通用 WYSIWYG 编辑、Mermaid 自动解析和托管分享也不在当前范围内。
  • 关键数据： JavaScript｜Stars 22,713｜Today +4,260｜Forks 1,469｜License MIT｜最近更新 2026-08-27｜Topics：Agent Skills、Architecture as Code、Code Visualization、Data Flow Diagram。

5. JetBrains/go-modern-guidelines

  • 项目简介： 这是 JetBrains 为 Coding Agent 准备的现代 Go 编码指南，覆盖 Go 1.0 到 1.27 的常用能力，也包含 modernize 分析器针对的模式。它支持 Junie、Claude Code、Codex、Cursor，并可通过 Agent Skill 形式接入其他工具。
  • 为什么火： 模型会受训练截止时间和旧代码频率影响，即使知道新语法，也常回到更常见的旧写法。这个仓库把目标 Go 版本与现代惯用法放进 Agent 的执行上下文，今天增加 314 Stars。
  • 技术亮点： 指南不仅列出语法更新，还要求 Agent 根据项目声明的 Go 版本选择标准库与语言特性，优先使用较新的惯用法。Marketplace 集成会在首次使用时安装小型 Go CLI，让规则能随仓库更新。
  • 适用场景： 适合升级 Go 代码库、审查 AI 生成代码，或让团队内多个 Coding Agent 使用同一套版本约束。它不能替代编译、测试、静态分析和基准测试；集成还要求本机 Go 工具链可用。
  • 关键数据： Go｜Stars 2,018｜Today +314｜Forks 62｜License Apache-2.0｜最近更新 2026-08-19｜Topics：Go、Coding Agent、AI Agents、Developer Tools。

6. anthropics/claude-plugins-official

  • 项目简介： 这是 Anthropic 管理的 Claude Code 插件目录，内部插件和合作伙伴、社区维护的外部插件分开组织。一个插件可以打包命令、Agent、Skill、Hooks 与 MCP 配置，再通过 Claude Code 的插件系统安装。
  • 为什么火： Claude Code 的扩展能力正在从零散仓库走向统一发现和分发。官方目录为名称、更新和迁移提供稳定入口，也让 Skill Bundle 可以从固定路径暴露给用户，今天增加 290 Stars。
  • 技术亮点： 插件名称采用不可变 slug，确需更名时由顶层 renames 映射为已有安装自动迁移。目录既支持仓库内插件，也支持固定提交与子目录指向的外部插件，降低分发时的版本漂移。
  • 适用场景： 适合为 Claude Code 增加专业开发能力，或把团队流程封装成可安装插件。Anthropic 不能控制第三方插件包含的 MCP Server、文件或软件，安装前仍应检查来源、权限与更新；目录代码采用 Apache-2.0，各插件许可证需分别确认。
  • 关键数据： Python｜Stars 34,621｜Today +290｜Forks 3,907｜License Apache-2.0（插件各自许可）｜最近更新 2026-08-27｜Topics：Claude Code、MCP、Skills。

7. K-Dense-AI/scientific-agent-skills

  • 项目简介： Scientific Agent Skills 是面向科研任务的 Agent Skill 库，仓库列出 163 个 Skill 与 100 多个数据库入口，覆盖生物信息学、化学、医学、药物发现、材料科学、实验自动化和科研写作。
  • 为什么火： 通用 Agent 很难同时掌握数据库入口、领域格式和实验流程。这个仓库把这些知识拆成可安装模块，并兼容 Claude Code、Codex、Cursor 等支持开放 Agent Skills 标准的工具，今天增加 494 Stars。
  • 技术亮点： 每个 Skill 以 SKILL.md 描述流程，可附带脚本、参考资料和测试；凡是带脚本的 Skill 都要求测试套件，CI 会阻止缺少测试的工具进入仓库。数据库访问与多步骤科研流程也被整理成可组合能力。
  • 适用场景： 适合文献检索、组学分析、化学信息学、科研绘图和实验流程辅助。医学影像等模块明确面向研究用途；Agent 输出不能替代临床判断、实验复核、数据许可审查或领域专家签字。
  • 关键数据： Python｜Stars 35,227｜Today +494｜Forks 3,387｜License MIT｜最近更新 2026-08-24｜Topics：Agent Skills、AI Scientist、Bioinformatics、Drug Discovery。

8. DietrichGebert/ponytail

  • 项目简介： Ponytail 是一套约束 Coding Agent 的规则、Skill 与插件。它要求 Agent 在写代码前依次检查需求是否必要、仓库是否已有实现、标准库或原生平台是否已经支持，最后才写满足任务的最小实现。
  • 为什么火： AI 编程降低了生成代码的成本，也放大了重复依赖、过度抽象和维护负担。Ponytail 把资深开发者的克制编码习惯封装成可安装能力，README 列出 20 种兼容 Agent，今天增加 1,610 Stars。
  • 技术亮点： 作者在真实 FastAPI + React 仓库上测试 12 个功能任务、每组 4 次。Haiku 4.5 测试中，相比无 Skill 基线，Ponytail 平均减少 54% 代码行、20% 成本和 27% 时间，同时保留安全检查；仓库公开方法、逐任务结果与复现配置。
  • 适用场景： 适合经常发现 Agent 引入多余组件、依赖或抽象的团队。基准只覆盖特定模型、仓库和任务，不能外推到所有工程；项目也明确保留校验、错误处理、安全与无障碍要求，不能把“少写”理解成代码高尔夫。
  • 关键数据： JavaScript｜Stars 113,885｜Today +1,610｜Forks 6,228｜License MIT｜最近更新 2026-08-07｜Topics：Agent Skills、AI Agents、Developer Tools、LLM。

9. calesthio/OpenMontage

  • 项目简介： OpenMontage 是一套 Agent 视频生产系统，仓库描述包含 12 条生产 Pipeline、100 多个工具和 700 多个 Skill 与制作知识文件。用户给出主题或参考视频后，系统可连接研究、脚本、素材生成、配音、剪辑、字幕、合成与质检。
  • 为什么火： 单个视频模型解决的是“生成一段素材”，完整作品还需要镜头规划、成本控制、审批和后期。OpenMontage 把这些环节组织成可检查的制作流程，并展示真实素材与生成素材两类路线，今天增加 1,284 Stars。
  • 技术亮点： Pipeline 定义、阶段 Skill 与工具注册表共同决定执行路径；Backlot 本地看板会显示脚本、场景、素材、Provider 选择与成本，并在渲染前提供逐镜头审批。最终合成可使用 Remotion 与 FFmpeg，交付前检查媒体解码、帧、音量和字幕。
  • 适用场景： 适合希望用 Coding Agent 组织解说片、纪录短片、产品片和社交视频的创作者或小团队。高质量生成仍依赖外部图像、视频与语音 Provider，密钥、费用和服务条款不会因开源编排层而消失；本地环境还需 Python、Node.js 与 FFmpeg。
  • 关键数据： Python｜Stars 52,222｜Today +1,284｜Forks 6,545｜License AGPL-3.0｜最近更新 2026-08-22｜Topics：Agentic AI、Video、FFmpeg、Claude、Copilot。

10. rohitg00/ai-engineering-from-scratch

  • 项目简介： 这套开源课程包含 20 个阶段、511 节课，使用 Python、TypeScript、Rust 与 Julia，从线性代数、深度学习和 Transformer 一路覆盖 RAG、MCP、Agent、多智能体与生产基础设施。
  • 为什么火： 很多 AI 教程停在调用框架，这个项目要求学习者先从数学和小型实现理解机制，再用生产库完成同一任务，并保留可运行成果。课程还能通过 Agent Skill 在 Coding Agent 里持续记录进度，今天增加 547 Stars。
  • 技术亮点： 每节课遵循 Problem、Concept、Build It、Use It、Ship It 的路径，目录同时保存可运行代码、课程文档和交付物。最终产物可以是 Prompt、Skill、Agent 或 MCP Server，学习状态写入项目文件，方便跨会话继续。
  • 适用场景： 适合希望系统补齐 AI 工程基础、并愿意亲手推导和运行代码的开发者。511 节课意味着高时间投入，仓库也明确不走“五分钟视频”或复制部署路线；只想快速接入模型接口的人更适合先选单一阶段。
  • 关键数据： Python｜Stars 50,090｜Today +547｜Forks 8,707｜License MIT｜最近更新 2026-08-23｜Topics：AI Engineering、Agents、Course、Deep Learning。
