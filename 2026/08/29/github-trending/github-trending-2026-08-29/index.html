今天的 GitHub 热榜几乎把 AI 开发工具的一整条链路摆在了一起：读懂代码、封装插件、补齐科研工作流、生成架构图，再把结果接到视频和图像生产。开发者关注的焦点已经落到一个更务实的问题——模型拿到什么上下文，最后能交付什么。

榜单也有两个反向信号。God’s Eye View 靠公开空间数据和 3D 地球冲到前列，screenshot-to-code 这样的成熟项目仍在吸收新增关注；今天并非只有 Agent 框架受益，能把真实数据或明确输入变成可操作界面的工具同样吃香。

1. tt-a1i/archify

项目简介： 把代码库或系统描述转换成可交互的架构图，并导出自包含 HTML、SVG、PNG 和视频等格式。

为什么火： 一天新增 4,562 Stars，说明“让编码 Agent 解释复杂系统”已经从锦上添花变成高频需求。它没有停在文本转图，而是把图当作可验证的工程产物。

技术亮点： Agent 先生成带类型的 JSON 中间表示，Archify 再确定性编译为 HTML/SVG；支持架构、流程、时序、数据流和生命周期图，也能做 Before / Delta / After 变更比较。

适用场景： 适合架构评审、代码库导览、变更说明和技术方案沟通。边界也很明确：图的可信度依赖输入与中间表示，工具不会替团队证明业务假设正确。

关键数据： JavaScript；Stars 27,952；Today +4,562；Forks 1,769；License MIT；最近更新 2026-08-28；Topics agent-skills、architecture-as-code、architecture-diagram、claude-skill、code-visualization；Homepage https://tt-a1i.github.io/archify/

2. K-Dense-AI/scientific-agent-skills

项目简介： 面向科研场景的 Agent Skills 集合，覆盖生物、化学、医学、药物发现与科学计算，并提供大量数据库连接能力。

为什么火： 科研 Agent 的难点往往不是“会聊天”，而是能否按领域工作流调用正确数据库和分析步骤。163 个技能与 100+ 数据库把这部分知识打包成可复用组件。

技术亮点： 技能兼容 Cursor、Claude Code、Codex 等宿主，并配套安全扫描和技能测试。它更像科研方法与工具接口的目录，而不是能独立承担科学结论的通用模型。

适用场景： 适合做文献检索、数据分析原型和实验前的信息整理；涉及临床、药物与高风险结论时，仍需专家审阅、数据质量控制和可复现实验。

关键数据： Python；Stars 36,789；Today +720；Forks 3,496；License MIT；最近更新 2026-08-28；Topics agent-skills、ai-scientist、bioinformatics、chemoinformatics、claude；Homepage https://k-dense.ai

3. anthropics/claude-plugins-official

项目简介： Anthropic 维护的 Claude Code 官方插件目录，包含内部插件和经过目录审核的第三方插件。

为什么火： 编码 Agent 的竞争开始延伸到插件分发和能力组合。官方目录降低发现成本，也给插件结构、命名和提交方式提供了统一入口。

技术亮点： 插件可包含清单、MCP 配置、命令、Agent 与 Skills；名称发布后保持不变，便于安装和更新。官方 README 同时提醒：目录收录不等于 Anthropic 能持续验证第三方软件行为。

适用场景： 适合希望扩展 Claude Code 工作流的开发者和团队。安装前仍要审查插件来源、权限、外部服务与更新策略，尤其是会访问文件或运行 MCP 服务的插件。

关键数据： Python；Stars 35,083；Today +457；Forks 3,938；License Apache-2.0；最近更新 2026-08-28；Topics claude-code、mcp、skills；Homepage https://code.claude.com/docs/en/plugins

4. bilawalsidhu/gods-eye-view

项目简介： 浏览器中的开源空间情报界面，把飞机、船舶、卫星、地震、交通和公共摄像头等公开信号叠加到写实 3D 地球。

为什么火： 一天新增 3,829 Stars，吸引力来自“电影级界面 + 真实公开数据”的反差。它把分散在多个网页的开放信号收拢成可探索的空间视图。

技术亮点： 项目基于 WebGL/Cesium 类地理可视化栈，并加入实时图层和语音交互；README 会区分直播信号与模型化视图。完整体验依赖若干外部数据与模型服务密钥。

适用场景： 适合 OSINT 教学、地理信息可视化和态势界面原型。公开数据并不自动等于可无条件传播，使用者仍需处理隐私、误判、延迟与数据许可。

关键数据： JavaScript；Stars 11,252；Today +3,829；Forks 2,281；License MIT（LICENSE）；最近更新 2026-08-28；Topics 3d-globe、cesium、flight-tracking、geospatial、geospatial-intelligence；Homepage https://maptheworld.ai/

5. abhigyanpatwari/GitNexus

项目简介： 在本地把代码库索引为知识图谱，再通过 Web UI、CLI 与 MCP 工具向编码 Agent 暴露依赖、调用链、聚类和执行流。

为什么火： 编码模型能读文件，却经常漏掉跨文件依赖。GitNexus 把“代码上下文”做成图结构，正好击中大型仓库里最容易导致盲改的部分。

技术亮点： 索引结果可供 17 个 MCP 工具、资源和引导提示使用，并自动生成 Agent 上下文文件。浏览器体验强调零服务器，但 CLI/MCP 路径仍涉及本地索引与编辑器配置。

适用场景： 适合遗留系统理解、影响分析和 Agent 辅助重构。许可证仅允许非商业用途；企业采用前需要单独确认授权，知识图谱也不能替代测试和代码审查。

关键数据： TypeScript；Stars 46,190；Today +202；Forks 5,104；License PolyForm Noncommercial 1.0.0（非 OSI）；最近更新 2026-08-28；Topics —；Homepage https://gitnexus.vercel.app

6. JetBrains/go-modern-guidelines

项目简介： JetBrains 为编码 Agent 准备的现代 Go 指南，帮助模型按项目 Go 版本选择新语法和标准库惯用法。

为什么火： 模型训练语料天然偏向旧写法。这个仓库把 Go 1.0 到 1.27 的常用现代化规则交给 Agent，解决的是很具体的“代码能跑但写得过时”。

技术亮点： 指南会从 go.mod 判断版本，覆盖 modernize 分析器相关能力，例如 slices.Contains、cmp.Or 与新版错误处理。它不修改编译器，只给 Agent 增加版本感知的编码参考。

适用场景： 适合维护跨版本 Go 项目、统一 Agent 生成风格和做现代化迁移。规则必须服从项目最低版本与团队约定，不能把新语法强塞进旧工具链。

关键数据： Go；Stars 2,636；Today +574；Forks 79；License Apache-2.0；最近更新 2026-08-19；Topics ai-agents、coding-agent、developer-tools、go、golang；Homepage —

7. calesthio/OpenMontage

项目简介： 把研究、脚本、素材生成、剪辑和合成串成 Agent 工作流的开源视频生产系统，提供 12 条生产管线、100+ 工具和大量技能文件。

为什么火： 生成式视频的瓶颈正在从单个镜头转向整条生产链。OpenMontage 把素材检索、真实视频剪辑、配音与渲染放进同一个可编排系统，因此持续获得关注。

技术亮点： 项目连接 FFmpeg、Remotion、库存素材和多家图像/视频/语音服务；零密钥也能走部分开源工作流，更多能力则依赖外部服务与成本。

适用场景： 适合内容团队搭建可修改的视频流水线和 Agent 导演实验。AGPL-3.0 会影响网络服务部署方式，第三方模型费用、素材权利和结果质检也需要单独管理。

关键数据： Python；Stars 53,413；Today +1,144；Forks 6,658；License AGPL-3.0；最近更新 2026-08-22；Topics agent、agentic-ai、ai、claude、copilot；Homepage https://www.openmontage.video/

8. abi/screenshot-to-code

项目简介： 把截图、Figma 设计或屏幕录制转换为 HTML、Tailwind、React、Vue 等前端代码。

为什么火： 它是榜单里更成熟的老项目，一天新增 326 Stars，说明“从视觉稿到可编辑代码”的需求仍然稳定，而模型升级也持续抬高可用上限。

技术亮点： 前端采用 React/Vite，后端采用 FastAPI，可接入多家模型；还支持从截图复用资产以及从录屏生成交互原型。结果质量与输入分辨率、模型选择和视觉资产提取有关。

适用场景： 适合快速搭原型、复刻布局和为设计稿生成第一版代码。生产环境仍要人工处理语义化、响应式、无障碍、状态逻辑和版权问题。

关键数据： Python；Stars 75,631；Today +326；Forks 9,223；License MIT；最近更新 2026-08-14；Topics —；Homepage https://screenshottocode.com

9. cursor/plugins

项目简介： Cursor 官方插件规范与插件集合，每个插件通过独立清单封装技能、规则和团队工作流。

为什么火： 官方插件仓库一天新增 246 Stars，信号不在单个功能，而在 Cursor 正把 Agent 能力从个人提示词升级为可分发、可维护的插件单元。

技术亮点： 仓库展示教学、持续学习、团队工具包、安全审查、插件脚手架等插件，并统一目录与 manifest 结构。插件代码能放大自动化，也会扩大权限和供应链风险。

适用场景： 适合希望标准化 Cursor 团队配置的开发者。README 标注 MIT，但具体插件若连接外部服务或包含第三方组件，仍应逐项核验权限和许可。

关键数据： TypeScript；Stars 5,995；Today +246；Forks 478；License MIT（README）；最近更新 2026-08-28；Topics —；Homepage —

10. freestylefly/awesome-gpt-image-2

项目简介： 围绕 GPT Image 2 的“Prompt as Code”模板与案例库，整理 500+ 逆向案例、20+ 模板和 Agent Skill。

为什么火： 一天新增 1,687 Stars，反映图像生成关注点已从一次性灵感转向可复制模板、分类检索和批量生产。它把提示词当作可维护资产，而不是聊天记录。

技术亮点： 仓库提供按场景组织的提示结构、案例图、网页浏览与技能安装方式。案例能缩短试错，但无法保证模型版本、内容政策和随机采样变化下仍复现同一结果。

适用场景： 适合运营设计、封面制作和团队沉淀视觉提示词。商用前要检查参考素材、人物肖像、品牌元素和生成服务条款。

关键数据： JavaScript；Stars 24,382；Today +1,687；Forks 2,405；License MIT；最近更新 2026-08-28；Topics agents、ai-image-generation、chatgpt、dsh-plugin、gpt-image-2；Homepage https://gpt-image2.canghe.ai
