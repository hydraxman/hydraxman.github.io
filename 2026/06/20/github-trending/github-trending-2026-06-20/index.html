今天这份 GitHub Trending，有个很明显的信号：开源世界正在从“会聊天的 AI”切进“能交付的 Agent”。榜单前十里，时间序列基础模型、代码知识图谱、沙箱代理框架、向量数据库、项目管理平台挤在一起，说明开发者已经不满足于单点模型能力，而是在找更完整的工程化栈。

另一个值得注意的对比是，榜上既有 freeCodeCamp 这种超级老牌教育项目，也有 GLM-5、flue、kilocode 这类非常新的 Agent 工具链。热度不只属于新概念，真正能落地、能降低复杂度、能直接拿去用的项目，反而更容易冲上来。

1. google-research/timesfm

  • 项目简介： TimesFM 是 Google Research 发布的时间序列基础模型，用预训练方式做预测任务。
  • 为什么火： 时间序列基础模型本来就是今年很热的一条线，而 Google Research 出手，天然会吸引量化、零售、供应链、能源预测这几拨人一起围观。
  • 技术亮点： 它把“先预训练、后适配”的 foundation model 思路搬进 forecasting，核心亮点不是某个单点指标，而是统一处理多种时间序列任务的能力。
  • 适用场景： 适合做销售预测、库存波动预测、金融时间序列研究，以及希望把传统 forecasting 管线升级成 foundation model 工作流的团队。
  • 关键数据： 语言：Python；Stars：24,012；Today Stars：+928；Forks：2,267；License：Apache-2.0；最近更新：2026-06-17；Topics：—；Homepage：https://research.google/blog/a-decoder-only-foundation-model-for-time-series-forecasting/

2. n0-computer/iroh

  • 项目简介： iroh 是一个基于密钥身份而不是固定 IP 的 Rust 模块化网络栈。
  • 为什么火： 大家这两年都在找更适合 P2P、边缘网络和设备互联的新抽象，而“拨号拨 key、不拨 IP”这个叙事很抓人。
  • 技术亮点： 它把身份、连接、发现和传输做成模块化 Rust 网络栈，强调 key-based addressing，对 NAT、动态网络环境更友好。
  • 适用场景： 适合去中心化应用、边缘设备互联、点对点文件同步，以及需要跨复杂网络环境建立稳定连接的系统。
  • 关键数据： 语言：Rust；Stars：10,220；Today Stars：+535；Forks：466；License：Apache-2.0；最近更新：2026-06-19；Topics：does-anyone-read-these, holepunching, memes, multipath, p2p, quic, realtime, rust；Homepage：https://iroh.computer

3. freeCodeCamp/freeCodeCamp

  • 项目简介： freeCodeCamp 是老牌开源编程学习平台，提供免费课程、练习和证书体系。
  • 为什么火： 老项目还能回到 Trending，通常意味着它又撞上了一个大众学习周期。现在 AI 编程热，把大量新手重新带回系统化课程。
  • 技术亮点： 真正的技术亮点不是框架花活，而是超大规模开源课程体系、练习平台和社区协作机制能持续运转。
  • 适用场景： 适合自学编程、做公益教育平台参考、设计训练营课程，或者搭建从入门到证书的学习路径。
  • 关键数据： 语言：TypeScript；Stars：449,789；Today Stars：+422；Forks：45,162；License：BSD-3-Clause；最近更新：2026-06-19；Topics：careers, certification, community, curriculum, d3, education, freecodecamp, javascript；Homepage：https://contribute.freecodecamp.org

4. obra/superpowers

  • 项目简介： superpowers 是一套把 AI coding agent 技能化、流程化的软件开发方法论。
  • 为什么火： Agentic engineering 是眼下最热的开发关键词之一，而 superpowers 提供的不是单个 agent，而是一整套技能化方法论。
  • 技术亮点： 亮点在于把技能、工作流、验证、代码审查这些环节拆成可复用单元，让 AI coding 从临场 improvisation 变成可复制流程。
  • 适用场景： 适合 AI coding 团队、内部工程规范建设、把 LLM 接入真实研发流程的技术负责人和平台团队。
  • 关键数据： 语言：Shell；Stars：233,215；Today Stars：+149；Forks：20,718；License：MIT；最近更新：2026-06-18；Topics：ai, brainstorming, coding, obra, sdlc, skills, subagent-driven-development, superpowers；Homepage：—

5. zai-org/GLM-5

  • 项目简介： GLM-5 是智谱开源的新一代模型项目，主打从 vibe coding 走向 agentic engineering。
  • 为什么火： “从 vibe coding 到 agentic engineering”这句定位本身就踩在行业情绪点上，再加上国产大模型开源，传播力很强。
  • 技术亮点： 它不只是在发模型权重，更在强调代码、代理、工程能力的一体化方向，这比单纯刷 benchmark 更接近开发者需求。
  • 适用场景： 适合本地部署模型、做编码助手、搭建代理式应用，或者评估国产模型在研发场景中的可用性。
  • 关键数据： 语言：Python；Stars：4,498；Today Stars：+434；Forks：456；License：Apache-2.0；最近更新：2026-06-18；Topics：agentic-ai, coding, llm, long-horizon；Homepage：https://z.ai/blog/glm-5.2

6. DeusData/codebase-memory-mcp

  • 项目简介： 一个高性能 MCP 代码智能服务器，把代码库索引成持久知识图谱并支持毫秒级查询。
  • 为什么火： MCP 生态最近很热，而“把整个代码库压成知识图谱，还能毫秒级查”这件事直接击中了上下文成本焦虑。
  • 技术亮点： 它把代码智能做成持久 memory 层，支持多语言索引、低延迟检索和更省 token 的上下文获取方式。
  • 适用场景： 适合大型代码库问答、IDE 智能检索、agent 读代码、跨仓库知识导航，以及 MCP server 基建。
  • 关键数据： 语言：C；Stars：8,034；Today Stars：+171；Forks：620；License：MIT；最近更新：2026-06-19；Topics：aider, ast, claude-code, code-analysis, code-intelligence, codex, cursor, cypher；Homepage：https://deusdata.github.io/codebase-memory-mcp/

7. alibaba/zvec

  • 项目简介： zvec 是阿里开源的轻量级、嵌入式向量数据库，强调 in-process 和高性能。
  • 为什么火： 向量数据库赛道已经从“能不能用”变成“够不够轻、够不够快”，zvec 这种 in-process 路线正好切中轻量部署需求。
  • 技术亮点： 最大亮点是嵌入式、轻量级和高性能，省掉单独维护外部向量库服务的复杂度，特别适合本地或单机侧场景。
  • 适用场景： 适合 RAG 原型、本地 AI 应用、边缘检索、单体服务内嵌语义搜索，以及低运维成本场景。
  • 关键数据： 语言：C++；Stars：11,567；Today Stars：+163；Forks：675；License：Apache-2.0；最近更新：2026-06-17；Topics：agent-skills, db, embedded, faiss, hnsw, llm-memory, local, rag；Homepage：https://zvec.org

8. withastro/flue

  • 项目简介： flue 是 Astro 团队推出的 sandbox agent framework，聚焦安全隔离的代理运行环境。
  • 为什么火： Agent 框架很多，但真正把 sandbox 讲清楚的不多。开发者现在越来越关心 agent 的安全边界，所以 flue 容易被关注。
  • 技术亮点： 它把“沙箱里的 agent”作为一等公民，重点不是堆功能，而是明确隔离、执行环境和工具调用边界。
  • 适用场景： 适合需要受控执行环境的 agent 平台、自动化工作流、浏览器/脚本代理实验，以及安全敏感业务。
  • 关键数据： 语言：TypeScript；Stars：5,787；Today Stars：+73；Forks：321；License：Apache-2.0；最近更新：2026-06-19；Topics：—；Homepage：https://www.flueframework.com

9. Kilo-Org/kilocode

  • 项目简介： kilocode 是一个一体化 agentic engineering 平台，围绕开源 coding agent 做交付闭环。
  • 为什么火： 开源 coding agent 进入平台化阶段后，市场在找的不再是“再来一个助手”，而是“能不能直接支撑交付流程”。
  • 技术亮点： 它把 coding agent、构建、迭代和团队协作打包成平台，强调从 build 到 ship 的闭环，而不是一次性 demo。
  • 适用场景： 适合 AI 研发平台、内部代码助手产品、团队级 agent 工具落地，以及想把 AI 编程变成正式生产力的公司。
  • 关键数据： 语言：TypeScript；Stars：22,852；Today Stars：+63；Forks：2,728；License：MIT；最近更新：2026-06-19；Topics：ai, ai-age, ai-coding, ai-developer-tools, chatgpt, claude, cli, gemini；Homepage：https://kilo.ai/

10. makeplane/plane

  • 项目简介： Plane 是开源项目管理平台，对标 Jira、Linear、Monday 和 ClickUp。
  • 为什么火： 大家对 Jira 的复杂和笨重早有怨气，Plane 这种现代开源替代品，天然具备持续热度。
  • 技术亮点： 它把任务、冲刺、文档和 triage 做成统一产品体验，技术上不是最花哨，但产品整合度很高。
  • 适用场景： 适合创业团队、开源团队、想自托管项目管理平台的公司，以及对 Jira/Linear 成本或控制权不满意的组织。
