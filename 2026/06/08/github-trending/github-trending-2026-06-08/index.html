  • 为什么火： AI Agent 技能市场还在升温，这个仓库把“全网检索+证据归纳”打包成可复用 skill，命中开发者对研究型 agent 的刚需。
  • 技术亮点： Python 实现，覆盖 Reddit、X、YouTube、HN、Polymarket 与 Web 多源检索，再做 grounded synthesis。
  • 适用场景： 适合做热点研究、情报汇总、竞品追踪、投资线索初筛。
