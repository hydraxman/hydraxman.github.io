今天的 GitHub Trending 把”上下文工程”和”Agent 基础设施”摆到了最显眼的位置：Headroom 用一层压缩中间件把 LLM token 砍到 5-40%，微软的 MarkItDown 继续刷榜稳坐文档→Markdown 转换的事实标准，而 ECC 这种面向 Claude Code/Codex 的 Agent harness 则在重新定义”编码 Agent 该长什么样”。从工具层到 Agent 层，整条工具链都在被重新打磨。

1. chopratejas/headroom

  • 项目简介：Headroom 是一个面向 LLM 上下文的”压缩中间层”，可以在工具输出、日志、文件、RAG 片段进入模型前先做高效压缩，宣称在不损失答案质量的前提下减少 60-95% 的 token 用量。
  • 为什么火：随着 Claude Code / Cursor / MCP 工作流在生产中铺开，超长上下文带来的 token 账单和性能衰减成了开发者的核心痛点。Headroom 把这个问题做成了一个可以即插即用的库 + 代理 + MCP server，三种形态覆盖大部分接入场景，正中当下”上下文工程”风口。
  • 技术亮点：同时提供 Python 库、HTTP 代理与 MCP server 三种使用方式；针对 Tool Output / 日志 / RAG chunk 等不同语义结构选用不同压缩策略；与 Anthropic / OpenAI / LangChain / FastAPI 等主流栈直接打通。
  • 适用场景：Agent 长会话降本、工具结果裁剪、RAG 召回后精简、Codex/Claude Code 中减少长日志吃光上下文窗。
  • 关键数据：语言 Python · Stars 5924 · Today 1,266 · Forks 419 · License Apache-2.0 · 最近更新 2026-06-02 · Topics agent, ai, anthropic, claude-code, compression, context-engineering, context-window, cursor · Homepage https://headroom-docs.vercel.app/docs

2. microsoft/markitdown

  • 项目简介：微软出品的 Python 工具，可以把 PDF、Office 文档、图片、音频等各种文件统一转换成 Markdown，是 AutoGen 生态的”文档预处理瑞士军刀”。
  • 为什么火：AI 文档解析仍是 RAG 落地最痛的一环。MarkItDown 由微软背书、与 AutoGen 等 Agent 框架深度集成，今天单日新增 3600+ stars，已迈过 14 万 stars 大关，成为这一品类的事实标准之一。
  • 技术亮点：统一 API 处理多模态输入；面向 LLM 友好的 Markdown 输出（保留表格/标题层级）；可作为 AutoGen 扩展或 LangChain pipeline 中的预处理节点。
  • 适用场景：企业知识库构建、RAG 文档入库、Office 文件批量转 Markdown、PDF → 结构化文本。
  • 关键数据：语言 Python · Stars 140905 · Today 3,616 · Forks 9592 · License MIT · 最近更新 2026-05-26 · Topics autogen, autogen-extension, langchain, markdown, microsoft-office, openai, pdf · Homepage —

3. affaan-m/ECC

  • 项目简介：ECC（Engineered Coding Companion）是一套面向 Claude Code、Codex、OpenCode、Cursor 等编码 Agent 的”性能优化框架”，把 Skills、Instincts、Memory、Security、Research-first 等最佳实践打包成可复用的 harness。
  • 为什么火：编码 Agent 进入”框架战争”阶段，开发者发现单纯调模型不够，需要一整套 skills/记忆/安全约束才能稳定产出。ECC 把社区里散落的最佳实践系统化，star 数已经攀到 20 万+，是近期最受关注的 Agent harness。
  • 技术亮点：跨 Agent CLI 通用（Claude Code/Codex/OpenCode/Cursor 都能挂载）；以 Skills + Instincts 双轨建模 Agent 行为；强调 research-first，让 Agent 先调研再动手；内置 memory 与 security 约束层。
  • 适用场景：团队级编码 Agent 标准化、企业内部 Agent 治理、需要长期记忆与安全审计的代码助手部署。
  • 关键数据：语言 JavaScript · Stars 203595 · Today 1,597 · Forks 31236 · License MIT · 最近更新 2026-06-02 · Topics ai-agents, anthropic, claude, claude-code, developer-tools, llm, mcp, productivity · Homepage https://ecc.tools

4. D4Vinci/Scrapling

  • 项目简介：Scrapling 是一个”自适应”Web 爬虫框架，从单次请求到全站抓取都用同一套 API，原生支持 Playwright、隐身模式与 MCP server 暴露。
  • 为什么火：AI Agent 需要的不再是”能下载 HTML”的爬虫，而是能被 Agent 直接调用、能扛反爬、能恢复结构变化的”智能采集层”。Scrapling 用一个框架同时解决传统爬虫和 MCP/Agent 时代的新需求，单日 1196 stars 体现了开发者的真实饥渴。
  • 技术亮点：适应性选择器（DOM 变了仍能命中目标）；内置 Playwright 隐身模式对抗反爬；同时暴露为 Python 库和 MCP server；XPath / CSS / AI-driven selector 多策略并存。
  • 适用场景：数据团队的稳定抓取管道、Agent 的实时网页查询工具、需要绕开反爬的金融/电商情报采集。
  • 关键数据：语言 Python · Stars 59041 · Today 1,196 · Forks 5704 · License BSD-3-Clause · 最近更新 2026-06-01 · Topics ai, ai-scraping, automation, crawler, crawling, crawling-python, data, data-extraction · Homepage https://scrapling.readthedocs.io/en/latest/

5. nesquena/hermes-webui

  • 项目简介：Hermes-WebUI 是 Hermes Agent 的浏览器前端：把这款开源个人 AI Agent 从终端 TUI 搬进了 Web，可以在浏览器里完整使用其工具调用、技能、记忆与多模型路由。
  • 为什么火：Hermes Agent 本身在终端用户里口碑很好，但很多人卡在”我想要个 ChatGPT 一样的网页”。这个官方 WebUI 把入口门槛打掉，单日涨 1725 stars，反映了”开源个人 Agent + 自托管”路线的旺盛需求。
  • 技术亮点：后端复用 Hermes Agent 全部 toolset（terminal/browser/skills/memory）；前端走流式响应；支持多 provider/多模型切换；保留 CLI 体验同时新增可视化对话、技能/记忆管理面板。
  • 适用场景：想要自托管 ChatGPT 替代品、本地化执行命令/调用工具的个人开发者、需要可审计 Agent 行为的小团队。
  • 关键数据：语言 Python · Stars 12452 · Today 1,725 · Forks 1528 · License MIT · 最近更新 2026-06-02 · Topics agent, ai-agents, hermes, hermes-agent, nous-research · Homepage https://get-hermes.ai/

6. reconurge/flowsint

  • 项目简介：FlowSint 是一个面向 OSINT（公开来源情报）的可视化流程引擎，让调查人员把搜索、解析、关联、可视化串成可复用的 flow。
  • 为什么火：近一年 OSINT 工具圈持续向”可视化 + AI”演进，FlowSint 用类似 n8n / Langflow 的画布形式把调查动作图形化，对非工程背景的安全/记者用户很友好，单日 190 stars 不算爆款但增长稳健。
  • 技术亮点：TypeScript 全栈；节点式编辑器；可挂接外部数据源与 LLM 作为节点；导出/分享调查流程。
  • 适用场景：安全研究、调查记者、企业反欺诈/品牌保护团队的 OSINT 工作流编排。
  • 关键数据：语言 TypeScript · Stars 4433 · Today 190 · Forks 580 · License Apache-2.0 · 最近更新 2026-06-02 · Topics investigation, osint, python, recon · Homepage https://flowsint.io

7. OpenBMB/VoxCPM

  • 项目简介：VoxCPM 是 OpenBMB 推出的语音版 CPM 模型，主打端到端语音对话能力，能直接处理语音输入并以语音回复，是面向消费级硬件优化的开源语音大模型。
  • 为什么火：端到端语音模型（类似 GPT-4o 语音模式）一直是开源社区的硬骨头，OpenBMB 在 MiniCPM 系列上的口碑加上 VoxCPM 的小体积/可本地跑的卖点，使其在中文 AI 圈快速扩散，单日 779 stars。
  • 技术亮点：语音-文本一体化建模，避免传统 ASR→LLM→TTS 三段式延迟；模型规模相对友好，可在消费级 GPU 部署；OpenBMB 的 CPM 系列预训练经验加持。
  • 适用场景：本地语音助手、车机/智能音箱原型、客服与教育领域的低延迟语音交互。
  • 关键数据：语言 Python · Stars 25021 · Today 779 · Forks 2876 · License Apache-2.0 · 最近更新 2026-05-22 · Topics audio, deeplearning, minicpm, multilingual, python, pytorch, speech, speech-synthesis · Homepage https://voxcpm.com

8. stefan-jansen/machine-learning-for-trading

  • 项目简介：Stefan Jansen 同名图书《Machine Learning for Algorithmic Trading》的官方代码仓库，覆盖从因子构建、回测、深度学习到强化学习交易的完整 Notebook 体系。
  • 为什么火：每逢市场波动加剧或者 AI 量化话题升温，这个老牌仓库就会重新登上 Trending。它内容体系完整、可直接跑、配合书籍系统讲解，是想入门量化的开发者最稳的起点之一，单日 570 stars。
  • 技术亮点：200+ Jupyter Notebook 覆盖 alpha 因子、组合优化、深度学习、RL；使用 Zipline / Backtrader / PyTorch 等主流栈；按章节组织，便于学习路径递进。
  • 适用场景：量化交易自学、研究生课程教材、机构内部 ML 量化培训。
  • 关键数据：语言 Jupyter Notebook · Stars 18384 · Today 570 · Forks 5218 · License — · 最近更新 2024-08-18 · Topics artificial-intelligence, data-science, deep-learning, finance, investment, investment-strategies, machine-learning, ml4t-workflow · Homepage https://ml4trading.io

9. jamwithai/production-agentic-rag-course

  • 项目简介：一门面向”生产级 Agentic RAG”的开源课程仓库，重点不是 Demo，而是怎么把 Agent + RAG 真正部署上线、监控、调优。
  • 为什么火：2026 年 RAG 早已过了拼 Demo 的阶段，企业需要的是可观测、可评测、可治理的生产级 Agentic RAG。这门课程精准命中招聘和落地痛点，虽然今天只新增 31 stars，但累计 6300+ 已是同类课程头部。
  • 技术亮点：强调评测与监控而非花架子；覆盖 Agent + 检索 + 工具调用全链路；提供可直接复用的项目结构与代码模板。
  • 适用场景：后端/平台工程师入门 LLM 应用、企业内部 Agentic RAG 培训、求职作品集。
  • 关键数据：语言 Python · Stars 6335 · Today 31 · Forks 1486 · License MIT · 最近更新 2026-04-05 · Topics — · Homepage —

10. supermemoryai/supermemory

  • 项目简介：Supermemory 是一个开源的”个人/团队记忆层”，把浏览历史、笔记、收藏、聊天记录等多源数据统一存储并对 Agent/聊天机器人开放查询接口。
  • 为什么火：记忆是 Agent 时代被反复提起的”下一个 RAG”。Supermemory 主打”一次记入，处处可查”的开源记忆平台，定位介于 Mem0 与 Pieces 之间，单日 677 stars，TypeScript 栈对前端社区友好。
  • 技术亮点：TypeScript 全栈，部署门槛低；统一多源数据 schema；提供 API/SDK 让外部 Agent 直接调用记忆；可自托管，保护隐私。
  • 适用场景：个人知识管理、AI 助手的长期记忆后端、团队共享上下文层。
