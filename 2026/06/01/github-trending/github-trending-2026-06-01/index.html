01. harry0703/MoneyPrinterTurbo

  • 项目简介：国产开源短视频自动化项目，输入主题或脚本即可由 AI 大模型生成文案、配音、字幕和素材，并一键合成高清竖屏视频。
  • 为什么火：AI 短视频赛道始终是流量富矿，这个仓库胜在「开箱即用 + 全中文」，再加上近期接入更多大模型，量产 TikTok/抖音/视频号内容的个人创作者持续涌入。
  • 技术亮点：Python + Streamlit Web UI 与 FastAPI 后端；接入 OpenAI/Moonshot/DeepSeek 等多家 LLM；素材来源 Pexels/Pixabay；用 MoviePy/FFmpeg 拼接配音字幕，支持本地一键运行。
  • 适用场景：自媒体批量产能、口播/资讯/故事类短视频、电商种草以及做 AI 视频流水线 demo。

02. microsoft/markitdown

  • 项目简介：微软官方推出的「万物转 Markdown」工具，把 PDF/Word/PPT/Excel/图片/音频/HTML 等格式统一转换成适合喂给 LLM 的 Markdown。
  • 为什么火：RAG 与 Agent 工作流里「数据预处理」是绕不开的痛点，markitdown 提供了一个简洁、统一、官方背书的入口，最近版本补齐了 OCR 与多媒体描述能力，被各类知识库项目大量引入。
  • 技术亮点：Python 库 + CLI；模块化转换器架构，针对每种格式各写一个 reader；可选接入 OpenAI 等多模态模型对图片/音频生成文字描述；支持 MCP server，直接被 Claude/Cursor 等客户端调用。
  • 适用场景：RAG 数据入库、企业文档智能问答、Agent 文件读取工具、批量内容清洗。
  • 关键数据：语言 Python · Stars 134,605 · Today 2,759 · Forks 9,207 · License MIT · 最近更新 2026-05-26 · Topics: autogen, autogen-extension, langchain, markdown, microsoft-office, openai, pdf · Homepage: —

03. D4Vinci/Scrapling

  • 项目简介：号称「不会被检测的」自适应 Python 爬虫框架，主打高性能、自动重定位失效选择器、内置反爬绕过。
  • 为什么火：爬虫生态长期被反爬机制压制，Scrapling 把 stealth 浏览器、自适应选择器与异步抓取打包成一个 API，开发者社区把它视作 Scrapy + Playwright 的轻量替代品，最近版本继续在反指纹方面发力。
  • 技术亮点：Python；同步/异步两套 API；底层封装 lxml、Camoufox、Playwright stealth；元素自动重定位（页面结构变了也能命中）；性能号称比 BeautifulSoup 快数倍。
  • 适用场景：数据采集、SEO 监控、价格追踪、AI 训练语料抓取、竞品情报。

04. nesquena/hermes-webui

  • 项目简介：为 Hermes Agent（命令行多 Agent 框架）打造的浏览器端 Web UI，把会话、工具调用、子 Agent 编排可视化呈现。
  • 为什么火：Hermes Agent 近期热度上升，但纯 CLI 体验对非开发者并不友好；这个 WebUI 把会话流、工具调用、技能加载做成图形界面，让大哥这种「Agent 重度用户」可以在浏览器里调度 cron 与子 Agent，刚发布就被收藏。
  • 技术亮点：Python 后端（FastAPI / Flask 风格）+ 前端组件；实时流式渲染 Agent 响应；与 Hermes 的工具/技能/记忆体系无缝对接。
  • 适用场景：Agent 开发调试、企业内部 Agent 操作台、给非技术同事提供可视化 Agent 入口。
  • 关键数据：语言 Python · Stars 9,843 · Today 320 · Forks 1,357 · License MIT · 最近更新 2026-05-31 · Topics: agent, ai-agents, hermes, hermes-agent, nous-research · Homepage: https://get-hermes.ai/

05. EveryInc/compound-engineering-plugin

  • 项目简介：Every.to 团队推出的「复合工程」插件，把多个 AI 工具/Agent 组合成可复用的工作流，属于「让 AI 替你写 AI 工作流」的元工具。
  • 为什么火：「复合工程（Compound Engineering）」概念由 Every 团队带火——核心是用 AI 自动搭流水线，而不是手撸 prompt。这个插件把方法论沉淀成可直接安装的产品，吸引大量 AI 工程师围观。
  • 技术亮点：TypeScript 编写，作为 IDE / Agent 平台插件分发；定义可组合的 Agent 节点，支持多模型协作与状态追踪。
  • 适用场景：AI 工程团队搭内部工作流、产品经理快速验证 AI 流程、教学演示「Agent 编排」概念。
  • 关键数据：语言 TypeScript · Stars 18,655 · Today 243 · Forks 1,406 · License MIT · 最近更新 2026-05-31 · Topics: compound, engineering · Homepage: https://every.to/guides/compound-engineering

06. github/docs

  • 项目简介：GitHub 官方文档站源码，包含产品文档、API 参考、平台教程，是开源世界最大规模的技术文档项目之一。
  • 为什么火：GitHub 近期密集更新 Copilot、Actions、Models 等产品线，文档站持续重构，配合新功能上线带来稳定的曝光与社区贡献。
  • 技术亮点：TypeScript + Next.js；多语言国际化；自动化校验流水线；文档即代码（docs-as-code）实践范本，自带翻译与可访问性工具。
  • 适用场景：学习大型 Next.js 文档站架构、贡献开源文档、作为内部技术文档站脚手架的参考实现。
  • 关键数据：语言 TypeScript · Stars 19,680 · Today 20 · Forks 67,283 · License CC-BY-4.0 · 最近更新 2026-05-29 · Topics: docs, works-with-codespaces · Homepage: https://docs.github.com

07. OpenBMB/VoxCPM

  • 项目简介：面壁智能 OpenBMB 团队开源的语音大模型 VoxCPM，主打端到端语音对话、克隆与多语种合成。
  • 为什么火：国内开源语音模型这两年百花齐放，VoxCPM 接续 MiniCPM 系列的口碑，主打小尺寸但效果对标商用 TTS，并支持本地推理，被语音类 Agent 开发者抢着 fork。
  • 技术亮点：Python + PyTorch；基于 CPM 架构的语音 tokenizer 与扩散/流匹配解码器；支持 zero-shot 音色克隆、多语言、低延迟流式合成。
  • 适用场景：语音助手、智能客服、播客/有声书自动化、多语言配音、本地隐私优先的语音生成。

08. revfactory/harness

  • 项目简介：一个极简的 HTML/CSS 实验场（harness），把可复用的 UI 组件、布局与动效收集成一个可直接预览的「单页画廊」。
  • 为什么火：前端圈最近兴起「single-file HTML demos」风潮，开发者用纯 HTML 文件展示创意设计与微交互；harness 把这种风格做成一个组织良好的样例集，迅速登上 Trending。
  • 技术亮点：纯静态 HTML/CSS/JS，无构建依赖；模块化组件，可直接复制粘贴；强调可访问性与原生 Web 平台能力。
  • 适用场景：前端学习与抄作业、设计师快速搭原型、给静态站做组件灵感库。
  • 关键数据：语言 HTML · Stars 4,535 · Today 318 · Forks 643 · License Apache-2.0 · 最近更新 2026-05-29 · Topics: claude-code, claude-code-plugin, harness, harness-engineering · Homepage: https://revfactory.github.io/harness/

09. FareedKhan-dev/train-llm-from-scratch

  • 项目简介：一个从零开始、用 Jupyter Notebook 一步步训练小型 LLM 的教学项目，覆盖分词、模型结构、训练、评测全流程。
  • 为什么火：「从零训练 LLM」依然是技术博主与学生最热衷的学习路径，作者把 Karpathy 风格的教程做成中文/英文友好的 Notebook 系列，配套代码可直接 run，特别适合面试准备季。
  • 技术亮点：Jupyter Notebook + PyTorch；自研 BPE 分词、Decoder-only Transformer；包含训练循环、梯度累积、混合精度、评测脚本与可视化。
  • 适用场景：学习 LLM 内部机制、教学/培训课程、给小模型做架构实验、面试项目展示。
  • 关键数据：语言 Jupyter Notebook · Stars 2,853 · Today 627 · Forks 429 · License MIT · 最近更新 2026-05-22 · Topics: gemini, large-language-models, llm, openai, training, transformers · Homepage: https://medium.com/@fareedkhandev/building-a-2-billion-parameter-llm-from-scratch-using-python-1325cb05d6fb

10. supermemoryai/supermemory

  • 项目简介：号称「给 AI 一颗第二大脑」的开源记忆层，把你浏览/收藏/聊天/文件统一沉淀进可被 Agent 检索的长期记忆。
  • 为什么火：AI Agent 普及后，「长期记忆」成为下一波竞争点，supermemory 既有完整产品（浏览器插件、Web 端、API），又开放核心代码，吸引大量开发者把它接入自己的 Agent 项目。
  • 技术亮点：TypeScript 全栈（Next.js + Hono）；向量检索 + 关系存储；浏览器扩展实时抓取上下文；提供 SDK 与 MCP server 让任意 Agent 客户端调用。
  • 适用场景：个人知识管理、Chrome 浏览记忆、Agent 长期上下文、企业内部「公司大脑」。
