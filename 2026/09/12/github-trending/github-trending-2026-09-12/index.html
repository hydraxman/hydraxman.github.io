一个要求 AI 把答案放在前面的 Skill（可复用的助手行为规则包），排到了今天 GitHub 日榜第一。i-have-adhd 的 Today 为 +3,440；第二名 God’s Eye View 则把公开的航班、卫星和地理数据放进可交互地球，Today 为 +3,642。一个减少阅读负担，一个扩大观察范围，它们都在改进人使用工具的方式。

2026 年 9 月 12 日的前十名还有本地编程工作台、WhatsApp 客户管理系统、个人知识库，以及纹理绘制和媒体管理软件。把这组项目放在一起看，值得关注的是输出能否看懂、执行能否审查、数据和设备能否由用户管理。日榜位置并不按新增 Star 简单排序，关注数也不等于产品成熟度或安全保证。

1. ayghri/i-have-adhd

  • 项目简介： 让编程助手先给行动、少绕弯的输出 Skill。它修改回答规则，不训练新模型，也不提供 ADHD 诊断或治疗；任何觉得 AI 回答冗长的人都可以使用。
  • 为什么火： Today +3,440。README 的前后对比直指一个常见摩擦：用户只想知道改哪个文件、下一步做什么，却要先读一段铺垫。低安装成本、可直接感知的表达变化，构成了它容易被尝试和分享的理由。
  • 技术亮点： 把行为要求写成可编辑的规则：行动优先、多步骤编号、压缩岔题、保留当前状态、以具体下一步结束。规则文件可以自行调整；简短输出仍应保留兼容条件和风险，不能把必要解释一并删掉。
  • 适用场景： 适合频繁与编程助手协作、希望降低阅读负担的开发者。先用同一项任务比较安装前后的回答，检查步骤是否更明确，而不是只比较字数。
  • 关键数据： 语言 Python；Stars 41,302；Today +3,440；Forks 2,347；License MIT；最近推送 2026-09-10 15:48:41 UTC；Topics adhd、claude-、claude-code-plugin、claude-skills、developer-tools、productivity；Homepage —。

2. bilawalsidhu/gods-eye-view

  • 项目简介： 在浏览器里探索公开空间数据的三维地球应用。它能把航班、船舶、卫星、地震和公共摄像头放在同一场景中，并提供目标跟踪、视角切换和语音控制。
  • 为什么火： Today +3,642。它把分散的数据源做成容易演示的交互场景：从全球视野切到一架飞机，再沿航线观察地面。README 也给出无密钥起步路径，降低了第一次体验的门槛。
  • 技术亮点： 数据图层模块化，实时目标可以带着相机、图层和追踪状态进入分享链接。拟真三维地图和语音功能依赖可选服务；热成像等是渲染风格，交通流含模拟，摄像头姿态也有估算，不能当作真实传感器测量。
  • 适用场景： 适合地理可视化教学、公开资料分析和交互演示。代码为 MIT，但数据和三维模型另有许可：内置海底电缆数据含非商业限制，商业项目须逐项清理或获得授权。
  • 关键数据： 语言 JavaScript；Stars 26,712；Today +3,642；Forks 5,462；License MIT（数据/模型另许可）；最近推送 2026-09-11 16:10:36 UTC；Topics 3d-globe、cesium、flight-tracking、geospatial、geospatial-intelligence、gis、osint、photogrammetry、satellite-tracking、spatial-intelligence、webgl、worldview；Homepage https://maptheworld.ai/。

3. nab138/iloader

  • 项目简介： 面向 iPhone、iPad 侧载操作的桌面工具，将 SideStore 安装、IPA 导入、证书和设备配对文件管理放进图形界面。
  • 为什么火： Today +36，是今天前十里相对温和的新增关注。它的价值在于减少侧载过程中的零散步骤和错误排查，不宜把这次上榜解读成突然爆发。
  • 技术亮点： 使用 Tauri 桌面框架，配合 Rust 设备通信组件与签名工具。支持开发证书和 App ID 查看、撤销以及错误建议；README 把应用自动刷新列在未来计划中，不能当成已有功能。
  • 适用场景： 适合需要在自己的设备上安装和管理合法 IPA 的用户。操作涉及 Apple ID、设备信任和配对文件，应只从项目仓库或 iloader.app 获取官方版本，并保管好账号与配对资料。源码为 MIT，品牌和媒体资产另有约束。
  • 关键数据： 语言 TypeScript；Stars 2,867；Today +36；Forks 199；License MIT（品牌资产另许可）；最近推送 2026-09-10 20:49:24 UTC；Topics idevice、ios、sideloading、sidestore；Homepage https://iloader.app。

4. melgarafael/DeskcommCRM

  • 项目简介： 面向通过 WhatsApp 获客和销售的自托管客户关系管理系统。会话、联系人、销售阶段和 AI 客服处在同一工作区，项目主要文档为葡萄牙语。
  • 为什么火： Today +126。相比独立聊天机器人，它把回答客户、识别线索、推进销售阶段和转交人工串在一起，更贴近销售团队每天处理的事情；是否有效仍取决于业务数据和人工接管流程。
  • 技术亮点： Next.js 与 Supabase 支撑应用，数据库行级权限用于隔离不同组织的数据；AI 检索按组织划分，并设置组织支出上限。WhatsApp 可接 WAHA 或 Meta 官方通道。MCP 是让 Agent 调用外部工具的通用连接协议；README 将内部 MCP 服务列为已交付、公共 MCP 接口列为规划，二者不能混为一谈。
  • 适用场景： 适合有服务器维护能力、以聊天成交的中小团队。自托管不免除服务器、模型和渠道费用，也不自动满足巴西 LGPD 数据保护法；使用非官方 WhatsApp 接入时，还须评估平台条款与账号风险。
  • 关键数据： 语言 TypeScript；Stars 1,260；Today +126；Forks 482；License MIT；最近推送 2026-09-11 16:04:39 UTC；Topics ai、ai-agents、chatbot、crm、customer-support、ecommerce、lgpd、mcp、multi-tenant、nextjs、nuvemshop、open-source、rag、sales-automation、self-hosted、supabase、typescript、waha、whatsapp、whatsapp-api；Homepage https://deskcomm.com.br。

5. vastsa/PI-Desktop

  • 项目简介： 为编程 Agent 提供独立桌面工作区：本地项目、会话、模型选择、代码差异、命令输出和插件集中管理，不要求注册 PI-Desktop 账号。
  • 为什么火： Today +545。它解决的是长会话管理和执行可见性：开发者可以在一个窗口里看计划、看修改、看命令结果，而不必把 Agent 工作流绑定在某个编辑器里。
  • 技术亮点： Electron 桌面外壳、Rust 宿主核心和 pi Agent 运行框架分工协作。Agent、Plan、Goal 三种模式分别强调直接执行、批准计划、批准目标与验收条件；高权限工具仍经过权限层，插件可以增加面板、工具和服务。
  • 适用场景： 适合多项目、多模型的编程用户。项目仍处于 Early Preview，接口与扩展行为可能变化；本地优先也不代表所有推理都离线，选择云模型时仍要评估代码外发范围。
  • 关键数据： 语言 TypeScript；Stars 2,734；Today +545；Forks 215；License LGPL-3.0；最近推送 2026-09-11 19:55:18 UTC；Topics ai-agent、coding-agent、desktop-app、electron、global、i18n、local-first、mcp、pi、pi-agent、pi-desktop、plugins、react、rust、typescript；Homepage https://pi-docs.aiuo.net。

6. armory3d/armorpaint

  • 项目简介： 用于三维模型 PBR 纹理绘制的图形工具。PBR 即基于物理的渲染，纹理用来描述表面的颜色、粗糙度等材质属性，供后续三维渲染使用。
  • 为什么火： Today +354。它让今天的榜单保留了专业创作软件的位置：对游戏和三维资产作者，能否直接完成材质制作，比是否加入聊天功能更重要。
  • 技术亮点： README 给出 Windows、Linux、macOS、Android、iOS 和 WebAssembly 的构建路径。代码许可为 Zlib；跨平台构建入口不等于各平台已有同等成熟、开箱即用的发行版。
  • 适用场景： 适合愿意编译或研究材质工作流的三维开发者。仓库明确面向开发者且可能不稳定，官方预编译版本收费以支持开发；代码开放不等于下载成品软件免费。
  • 关键数据： 语言 C；Stars 4,683；Today +354；Forks 531；License Zlib；最近推送 2026-09-11 17:02:05 UTC；Topics 3d、armorpaint、painting、texturing、tool；Homepage https://armorpaint.org。

7. alsk1992/CloddsBot

  • 项目简介： 自托管的 AI 交易终端，用自然语言连接预测市场、加密资产和期货平台，并提供行情、策略、回测及订单执行接口。
  • 为什么火： Today +627。把聊天助手接到真实交易接口，容易引来自动化交易开发者的兴趣。但 README 中的市场数量和策略数量是项目自述，不是盈利能力证明。
  • 技术亮点： TypeScript 服务整合消息渠道、WebChat、市场数据和交易执行。README 列出风险引擎、日亏损限制、熔断与紧急停止功能；这些设计仍需在目标平台和账户权限下验证，不能据此推断资金安全。
  • 适用场景： 适合研究交易接口和风险控制的开发者，先做只读行情或模拟环境实验。不要把宣传中的自主交易当作收益承诺，也不要向未经审查的 Agent 交出高权限账户或钱包；真实执行还涉及地区与平台限制。

8. nashsu/llm_wiki

  • 项目简介： 把文档逐步整理成相互链接 Wiki 的桌面知识库。与每次提问才临时检索并拼答案的方式相比，它会先生成可保存的知识页面，再持续维护页面与来源关系。
  • 为什么火： Today +640。长期积累资料的人常遇到同一个问题：搜索能找到文件，却很难看见文件之间的关联。持久 Wiki、关系图和原文追溯为反复研究同一主题提供了另一种整理方式。
  • 技术亮点： 导入分成分析与页面生成两步，配合内容哈希增量缓存和可恢复队列；生成页保存来源字段，可选向量检索补充关键词搜索。还提供只读原始来源的回答模式，便于把原文证据与模型整理区分开。
  • 适用场景： 适合论文阅读、长期研究和个人资料管理。页面与关系仍可能生成错误，需要人工审核；接入云模型时，资料可能发往模型服务。GPL-3.0 许可也意味着再分发修改版本时需要关注相应源码义务。
  • 关键数据： 语言 TypeScript；Stars 18,661；Today +640；Forks 2,131；License GPL-3.0；最近推送 2026-08-25 06:42:02 UTC；Topics —；Homepage —。

9. obra/superpowers

  • 项目简介： 给编程 Agent 使用的软件开发方法与 Skill 集合，覆盖需求澄清、计划、测试、调试、代码审查和分支收尾。
  • 为什么火： Today +731，累计 Stars 为 285,286。它的吸引力在于把开发过程中的检查点做成可触发的规则，让同一套工作要求跨编程工具复用；高关注度不代表每项任务都会更快。
  • 技术亮点： 强调先写会失败的测试、再实现功能的测试驱动开发，并把需求符合性与代码质量分成两轮审查。不同宿主分别安装，自动触发依赖对应集成；这些规则约束协作过程，不会替代真实测试与人工判断。
  • 适用场景： 适合中等以上改动、多人或多 Agent 协作，尤其是容易跳过测试和审查的项目。微小改动未必需要完整流程，可根据风险选用；可选可视化伴随功能的遥测也应按团队政策配置。

10. Sonarr/Sonarr

  • 项目简介： 面向 Usenet 和 BitTorrent 用户的剧集媒体管理工具，可监控更新、补齐缺集、整理命名，并在更高质量版本出现时按规则升级。
  • 为什么火： Today +174。它代表一种与 AI 无关但持续存在的需求：让个人媒体库按规则运转。自动化的对象清楚、结果也容易检查，是成熟工具重新获得关注的合理使用价值。
  • 技术亮点： 用 RSS 监控和下载器集成连接发现、获取与入库，包含失败下载重试、质量选择和可配置命名，并与 Plex、Kodi 等媒体系统联动。
  • 适用场景： 适合管理自有或已获授权媒体的用户。Sonarr 本身不授予内容版权，下载来源是否合法仍由使用者确认；服务也应配置访问控制，避免直接暴露到公网。
